## 1. 개요

### 1.1 한 줄 정의

3명의 미소녀 조사원과 펫 1마리로 팀을 꾸려 9개 섹터의 괴담 현장을 탐험하며 빌드를 완성하고,
살아서 탈출한 팀만 "파티덱"으로 남겨 상위 컨텐츠에 도전하는 모바일 쿼터뷰 익스트랙션 로그라이크.

### 1.2 핵심 재미

1. **현장 판단**: 더 위험한 경로로 가서 덱을 키울지, 지금 캠프에서 탈출해 덱을 지킬지.
2. **빌드 완성**: 캐릭터 고유 성장 + 시즌 스킬 + 시즌 장비가 한 런 안에서 쌓여 팀이 완성된다.
3. **교체 전투**: 3명을 상황에 맞게 교체하며 속성 약점과 속성 특성을 활용한다.
4. **탐험**: 일자형이 아닌 맵에서 무리, 수색 오브젝트, NPC를 찾아다닌다.

### 1.3 프로토타입 검증 목표

- D패드 + 공격 시 정지 + 추천 타겟 조작이 모바일에서 손에 맞는가.
- 섹터 1개가 1~2분, 런 1회가 15~20분 안에 끝나는가.
- 한 런에서 만든 파티덱이 런마다 체감될 만큼 다르게 나오는가.
- 탈출 여부를 고민하게 만드는 긴장이 생기는가.

### 1.4 범위

| 포함 | 제외 (구조만 유지) |
| --- | --- |
| 팀 편성 (3 캐릭터 + 1 펫) | 캐릭터 레벨 / 스킬 레벨 / 조사 도구 |
| 시즌 컨텐츠 "괴담 조사" 9섹터 런 | 펫 레벨 / 돌파 |
| 파티덱 저장 (팀 점수 포함) | BM, 재화 / 파견, 이벤트 컨텐츠 |
| 덱 컨텐츠 2종 | 서버, 계정, 랭킹 |
| 전투 HUD 13요소 | 스토리, 연출 컷신 |
| 소리 (효과음, 배경 음악, 환경음) | 캐릭터 음성 |

## 2. 전체 플레이 흐름

```
로비
 ├─ 괴담 조사 (시즌 컨텐츠)
 │    팀 편성 (3C + 1P)
 │      → 섹터 1 → 경로 선택 → 섹터 2 → 경로 선택 → 섹터 3
 │      → [체크포인트 캠프 1: 휴식 / 상점 / 탈출]
 │      → 섹터 4 → 섹터 5 → 섹터 6
 │      → [체크포인트 캠프 2: 휴식 / 상점 / 탈출]
 │      → 섹터 7 → 섹터 8 → 섹터 9 괴이(보스) 전투
 │      → 조사 팀 저장 (파티덱 + 팀 점수)
 │
 └─ 파티덱 컨텐츠 (저장된 덱 필요)
      ├─ 특급 괴이 토벌 (보스 타임어택)
      └─ 괴이 범람 (웨이브 서바이벌)
```

- 경로 선택에서 보너스 맵을 고르면 보너스 맵을 거친 뒤 원래의 다음 섹터로 이어진다.
- 파티덱이 저장되는 경우는 두 가지뿐이다: 캠프에서 탈출하거나, 섹터 9 보스를 격파하거나.
- 그 외(전멸, 런 포기)는 파티덱이 남지 않는다.

## 3. 조작과 전투 규칙

### 3.1 화면

- 스마트폰 가로 고정. 세로로 들면 회전 안내를 띄운다.
- 쿼터뷰(위에서 비스듬히 내려다보는 시점). 카메라는 필드 캐릭터를 따라간다.
- 화면 방식은 두 가지다. 기존 화면은 맵을 정면에서 비스듬히 내려다보고(네모 칸이 네모로 보인다), 마름모 화면은 45도 돌려 내려다본다(네모 칸이 마름모로 보인다). 마름모 화면은 시험판이다 (7.14절).
- PC 테스트용 키보드 조작을 함께 지원한다 (이동 WASD, 공격 J, 회피 K, 액티브 L, 궁극기 I, 펫 O, 교체 1/2/3).

### 3.2 이동

- 방향 패드(D패드). 누르고 있는 방향으로 이동하고 손을 떼면 멈춘다.
- **방향은 자유다**: 패드 가운데에서 손가락까지의 방향 그대로 간다 (예전에는 45도 단위의 8방향으로 꺾었다). 손잡이가 손가락을 따라가고, 둘레의 화살표 여덟 개 가운데 가장 가까운 것이 밝아진다.
- 빠르기는 얼마나 밀었는지와 상관없이 같다 (살짝 밀어도 제 속도로 걷는다). 가운데 근처(패드 너비의 11%)는 누르지 않은 것으로 본다.
- 키보드는 키의 조합이라 8방향 그대로다.

### 3.3 기본 공격

| 상황 | 동작 |
| --- | --- |
| 공격 버튼을 누름 | 이동이 멈추고 공격을 시작한다. 누르고 있는 동안 반복 공격 |
| D패드 입력 중 + 공격 (근거리 캐릭터) | D패드가 가리키는 방향으로 공격 |
| D패드 입력 중 + 공격 (원거리 캐릭터) | D패드 방향과 상관없이 추천 타겟에게 공격. 사거리 안에 적이 없을 때만 D패드 방향으로 공격 |
| D패드 미입력 + 공격 | 추천 타겟에게 공격 |
| 추천 타겟이 없음 | 마지막으로 바라본 방향으로 공격 |
| 공격 버튼에서 손을 뗌 | 현재 공격의 후딜레이가 끝나면 이동 가능 |

- **추천 타겟**: 사거리 안에서 가장 가까운 적. 벽에 가려진 적은 제외한다.
  추천 타겟에는 조준 마커를 표시해 누가 맞을지 미리 알려 준다. 근거리 캐릭터는 D패드를 누르지 않는 동안, 원거리 캐릭터는 항상 표시한다.
- **방향 보정**: 손가락으로 정확한 각도를 맞추기 어려우므로, 지정 방향 ±25° 안에 적이 있으면 그 적 쪽으로 보정한다. (8방향이던 때에 넣은 것이고, 자유 방향이 된 뒤에도 그대로 둔다)
- **조준 방식**: 캐릭터마다 표(characters.csv의 aim)에 적는다. 근거리(대검, 해머, 쌍검, 깃창)는 D패드 조준, 원거리(메카 건틀렛, 활, 산탄총, 기관단총, 부적)는 자동 조준이다. 액티브와 궁극기에도 같은 규칙을 쓴다.
- 근거리 캐릭터도 자동 조준으로 해 볼 수 있도록, 디버그 메뉴에 "근거리 자동 조준" 옵션을 둔다.
- 기본 공격의 타격 범위(부채꼴)는 화면에 그리지 않는다. 수치 표(fx.basicRange)를 1로 바꾸면 다시 그린다.
- 근접 캐릭터는 공격할 때 조준 방향으로 짧게 전진한다.
- 회피는 공격 동작을 끊고 나갈 수 있다.

### 3.4 회피

- D패드 방향(미입력 시 바라보는 방향)으로 짧게 대시한다. 대시 중 0.25초 무적.
- 잔여 카운트 기본 2회, 카운트당 3초에 1회 충전.

### 3.5 액티브 스킬 / 궁극기

- 방향 규칙은 기본 공격과 같다 (D패드 방향 또는 추천 타겟).
- **액티브**: 쿨타임 기반. 게이지가 차면 사용 가능. 일부 캐릭터는 잔여 카운트(충전 횟수)를 가진다.
- **궁극기**: 궁극기 게이지 100으로 사용. 공격 적중과 처치로 충전된다.
  필드 캐릭터는 100%, 오프 필드 캐릭터는 30% 비율로 충전된다.

### 3.6 펫 스킬

- 쿨타임 기반 버튼 1개. 팀에 편성한 펫의 스킬을 사용한다.

### 3.7 캐릭터 교체

- 화면 좌측의 교체 캐릭터 썸네일을 누르면 그 캐릭터가 같은 자리에 등장한다.
- 교체 쿨타임 1.5초 (팀 공유). 사망한 캐릭터로는 교체할 수 없다.
- 오프 필드 캐릭터도 액티브 쿨타임은 계속 돈다. 체력은 자연 회복되지 않는다.
- 필드 캐릭터가 사망하면 살아 있는 다음 캐릭터로 자동 교체된다.
- 3명이 모두 사망하면 전멸이다.

### 3.8 피해 계산 (초안)

```
피해 = 공격력 × 스킬 배율 × 치명타(기본 5%, 150%) × 약점 보정(1.3) × 버프·디버프 보정
```

장비 스킬의 피해는 별도 규칙을 쓴다 (7.5절).

### 3.9 자동 공격

궁극기 버튼 위의 작은 AUTO 버튼(키보드 T)으로 켜고 끈다. 켜 두면 주변의 적을 스스로 상대한다. 고른 것은 기기에 남아 다음에 들어와도 그대로다.

| 항목 | 규칙 |
| --- | --- |
| 하는 것 | 기본 공격, 액티브 스킬 (준비되는 대로) |
| 하지 않는 것 | 궁극기, 펫 스킬, 교체, 상호작용(상자·수색·출구), 회피. 모두 직접 누른다 |
| 직접 조작 | 언제나 먼저다. D패드(이동), 공격 버튼, 회피를 누르는 동안에는 자동이 손을 뗀다. 조작이 끝나면 바로 다시 맡는다. 스킬·교체 버튼은 자동 중에도 그대로 듣는다 |
| 다가가기 | 반경 안의 적이 닿지 않으면(사거리 밖이거나 벽에 가렸으면) 닿는 자리까지 걸어간다. 사거리의 85% 안으로 들어가면 멈춰서 친다. 벽에 막히면 길을 따라 돌아간다 |
| 반경 | 이쪽을 알아챈 적은 520px (화면에 보이는 넓이의 절반쯤. 사거리가 더 긴 캐릭터는 사거리까지). 아직 알아채지 못한 적은 300px 안에 있을 때만 먼저 건드린다 |
| 적이 없으면 | 제자리에 선다. 스스로 맵을 돌아다니지 않는다. 다음 무리까지는 직접 걸어가야 한다 |
| 돌아가는 길 | 걸어서 가는 길이 반경의 1.5배를 넘으면 쫓지 않는다 (벽 너머의 적을 쫓아 멀리 돌아가지 않게) |
| 대상 | 가까운 적부터. 한번 잡은 적은 조금 더 붙든다 (대상이 자꾸 바뀌어 왔다 갔다 하지 않게) |

- 자동은 "플레이어 대신 버튼을 눌러 주는 것"으로 만들었다. 그래서 조준·피해·쿨타임 같은 규칙은 손으로 할 때와 완전히 같다.
- 자기 둘레에서 터지는 액티브(라이의 에너지 방출)는 적이 그 범위 안에 들어왔을 때만 쓴다 (`skill_values.csv` 의 `<캐릭터>.active.autoRange`).
- 궁극기를 자동으로 쓸지는 `params.csv` 의 `auto.ult` 로 바꾼다: 0 = 직접 (지금 값) / 1 = 게이지가 차면 바로 / 2 = 정예·특급·보스가 반경 안에 있을 때만.
- 공격 예고를 피하는 것은 자동이 해 주지 않는다. 피할 때는 회피나 D패드를 직접 누른다.
- 수치는 `params.csv` 의 `auto.*` (반경 radius, 알아채지 못한 적의 거리 near, 멈춰서 치는 거리 reach).

### 4.1 UI 규칙

전달받은 UI 기본 컴포넌트(우편함 화면)에서 뽑은 규칙이다. 로비·편성·보상·팀 정보·결과 등 모든 창과 전투 HUD에 똑같이 적용한다.

| 항목 | 규칙 |
| --- | --- |
| 색 | 무채색(검정 ~ 회색 ~ 흰색)만 쓴다. 강조색은 라임 한 가지 |
| 강조색을 쓰는 곳 | 선택된 것(고른 캐릭터·펫, 다음 섹터), 지금 눌러야 하는 주 버튼, 눈여겨볼 값(팀 점수, 은화), 체력 게이지. 그 밖에는 쓰지 않는다 |
| 면 | 바탕 < 창 < 창 안의 줄 순서로 한 단계씩 밝아진다. 1px 회색 선과 작은 둥근 모서리로 나누고, 창은 선을 두 겹 두른다 |
| 버튼 | 알약 모양. 어두운 면 + 밝고 얇은 테두리 + 오른쪽 끝의 망점. 주 버튼은 라임으로 채우고 글자를 어둡게 쓴다 |
| 수량·상태 표시 | 검은 알약 (재화, 가방 칸 수, 약점 속성, 희귀도, 버프) |
| 칸 | 초상화·아이템 칸은 검은 둥근 사각형 |
| 글자 | 굵게. 본문은 흰색, 라벨은 회색 |
| 정보를 전하는 색 | 속성 4색, 희귀도, 위험·체력 부족의 빨강은 그대로 두되 띠·점·글자처럼 작은 면적에만 쓴다 |
| 배경 그림 | 로비의 배경 그림은 무채색으로 낮춰 깐다. 전투 맵은 게임 화면이므로 원래 색을 유지한다 |

조작 버튼(②~⑤, ⑨)은 흑백 톤으로 따로 정한다.

- 반투명한 회색 원판 위에 흰색 단색 아이콘을 놓는다. 글자(기본 공격, 회피 등)는 넣지 않는다.
- 상태는 색이 아니라 밝기와 고리로 알린다.
  - 쓸 수 있음: 아이콘이 밝고 테두리 고리가 또렷하다. 액티브는 고리가 굵고 빛난다.
  - 쿨타임 중: 어두운 덮개가 12시부터 시계 방향으로 걷히고, 남은 초가 숫자로 뜨고, 테두리 고리가 지난 만큼 차오른다.
  - 다시 쓸 수 있게 된 순간: 버튼이 살짝 튀고 흰 고리가 한 번 퍼져 나간다.
- 궁극기: 굵은 흰 고리가 게이지만큼 차오른다. 다 차면 고리가 빛나고, 고리에 박힌 돌기 네 개가 천천히 돈다.
- 원판·고리·쿨타임 덮개는 SVG로 그린다 (CSS 원뿔 그라디언트는 기기에 따라 실금이나 얼룩이 보였다).

- 미니맵은 지나간 곳만 밝혀진다. 탐험한 만큼 지도가 채워지는 구조다.
### 4.2 상태(버프·디버프) 표시

상태는 글자가 아니라 **네모난 아이콘**으로, 체력 아래에 보여 준다. 어디에 보여 줄지는 상태의 무게에 따라 나뉜다.

| 무리 | 무엇 | 보이는 곳 |
| --- | --- | --- |
| 핵심 상태 | 속성 특성의 상태(빌드업, 임팩트), 보호막, 궁극기·스킬로 얻는 한정 강화(집중 포화, 진혼, 진군, 깃발), 치명적인 디버프(화상 등) | 필드 캐릭터 머리 위(체력 막대 아래) **와** 왼쪽 위 ⑥ |
| 그 밖의 상태 | 장비가 가끔 주는 짧은 강화(처형, 역습, 잔상, 질주), 고유 성장·시즌 스킬의 짧은 강화(고양, 인계, 지휘), 대기 중인 팀원이 주는 상시 효과, 런 내내 남는 저주 | 왼쪽 위 ⑥ 에만 |

- **아이콘**: 검은 네모 칸에 흰 기호 하나. 기호는 효과의 종류를 뜻한다 (칼 = 공격력, 번개 = 공격 속도, 겹화살 = 이동 속도, 방패 = 받는 피해, 과녁 = 치명타, 고리 = 보호막, 쌓인 단 = 빌드업, 터지는 별 = 임팩트, 네 갈래 별 = 궁극기 강화, 깃발, 심장 = 체력, 불꽃 = 지속 피해).
- **구분**: 핵심 상태는 테두리가 강조색(라임), 디버프는 칸과 기호가 빨강이다.
- **남은 시간과 중첩**: 남은 시간은 칸이 위에서부터 어두워지는 것으로, 중첩은 오른쪽 아래의 숫자로 보인다. 시간제한이 없는 상시 효과는 어두워지지 않는다.
- **순서와 개수**: 치명적인 디버프 → 핵심 버프 → 그 밖의 버프 → 그 밖의 디버프 순서. 머리 위에는 최대 4개, 왼쪽 위에는 최대 8칸이며 넘치면 마지막 칸에 남은 수(+2)를 적는다.
- 지금은 플레이어에게 걸리는 전투 중 디버프(화상 등)가 없다. 디버프로 표시되는 것은 저주뿐이다. 몬스터가 거는 디버프를 넣을 때는 버프에 "디버프·핵심" 표시만 붙이면 머리 위에 빨간 아이콘으로 뜬다.
- 장비 스킬의 내용은 ⑪ 팀 정보 화면에서 확인한다.

## 5. 캐릭터

### 5.1 분류 체계

**등급 (괴담 대응 등급)**: S급 / A급. 프로토타입에서는 기본 능력치 차이만 둔다 (S급이 약 10% 높음).

**포지션 (담당)**

| 포지션 | 역할 |
| --- | --- |
| 타격 | 누킹 / 임팩트 효과 |
| 리더 | 범용 전투 능력 + 난전 |
| 지원 | 서브 딜링 / 버프, 패시브 특화 |

**속성 (능력 계통)** — 적 약점 판정과 전투 특성 두 가지에 쓰인다.

| 속성 | 방향성 | 전투 특성 (해당 속성 캐릭터 공통) |
| --- | --- | --- |
| 실체 | 순수한 강함 / 개인 강화 / 체급 | **체급**: 최대 체력 +15%, 받는 피해 -10% |
| 형상 | 긴 전투 템포 / 빌드업 기반 | **빌드업**: 공격 적중마다 중첩 +1 (최대 10, 중첩당 피해 +3%). 4초간 적중이 없으면 소멸 |
| 자연 | 확산 / 연계 / 환경 요소 활용 | **확산**: 적중한 적에게 "전이" 4초 부여. 전이 상태의 적을 기본 공격으로 치면 피해의 25%가 주변 적 1체에게 연쇄 |
| 반전 | 짧은 호흡의 임팩트 있는 전투 템포 | **임팩트**: 회피 또는 교체 등장 직후 2.5초간 피해 +35% |

- **약점**: 모든 적은 약점 속성 1개를 가진다. 약점 속성 캐릭터의 피해는 +30%.

### 5.2 로스터 (9명)

포지션마다 3명. 위 3명(에트나, 라이, 키온)은 기획 슬라이드의 진행 예시 캐릭터이며 전신 디자인이 있다.

| 이름 | 외형 | 무기 |
| --- | --- | --- |
| 에트나 | 분홍빛 단발, 빨간 재킷, 검은 반바지 | 검 (대검) |

### 5.5 궁극기의 작용 방식

궁극기가 "주변에 원형으로 터진다" 일색이 되지 않도록, 캐릭터마다 범위의 모양과 방식을 다르게 둔다.
명조의 공명 해방처럼 같은 궁극기라도 변신형·추적형·협공형·설치형으로 쓰임이 갈리는 구성을 참고했다.

| 캐릭터 | 방식 | 모양 | 잘 맞는 상황 |
| --- | --- | --- | --- |
| 에트나 | 즉발 + 잔류 | 전방 직선 (긴 균열이 남는다) | 좁은 골목, 줄지어 오는 적 |
| 라이 | 추적 | 범위 없음. 가까운 적부터 하나씩 낙뢰 | 흩어진 적, 정예 한 마리에 몰아치기 |
| 키온 | 저격 | 초장거리 관통 직선 + 표식 | 멀리 있는 보스, 뒤이은 딜 준비 |
| 카렌 | 연사 | 코앞의 부채꼴 5연사 | 달라붙은 무리. 끝나면 회피와 액티브가 돌아와 연계 |
| 라온 | 도약 강타 | 착지 지점의 큰 원 (유일한 원형 폭발) | 뭉친 무리 한가운데 |
| 유나 | 강화 상태 | 범위 없음. 자신의 연사가 강해진다 | 긴 교전, 보스 |
| 하루 | 연속 이동 베기 | 범위 없음. 적 사이를 오가며 벤다 | 흩어진 소형 적 |
| 로아 | 지연 폭발 | 범위 없음. 주변 모든 적에게 표식 → 일괄 폭발, 팀 회복 | 적이 사방에 깔렸을 때, 팀이 위험할 때 |
| 이브 | 협공 상태 | 범위 없음. 필드 캐릭터의 공격에 창이 따라 나간다 | 나팔을 불고 딜러로 교체해 싸우기 |

- 에트나, 라이, 키온은 이미 만든 궁극기 동작(도약해 내리꽂기, 주먹을 들었다 내리치기, 활을 끝까지 당겨 쏘기)을 그대로 쓴다. 판정의 모양만 바뀌었다.
- 이환(Neverness to Everness)의 스킬 구성은 자료를 직접 확인하지 못해 반영하지 못했다. 참고하고 싶은 캐릭터나 영상이 있으면 그 기술의 방식을 옮긴다.

### 5.4 캐릭터 애니 리소스

프로토타입은 도형 기반 플레이스홀더로 표현하되, 상태 구분은 기획 슬라이드의 목록을 따른다.
나중에 스프라이트 애니메이션으로 교체할 때 이 상태 이름을 그대로 쓴다 (11.1절).

## 6. 펫

괴담 조사 중 아이템 / 스펠처럼 쓰는 펫 스킬 1개를 가진다. 팀에 1마리만 편성한다.

| 펫 | 스킬 | 쿨타임 |
| --- | --- | --- |
| A 펑이 | 가까운 적에게 달려가 자폭. 범위 피해 300% + 넉백 | 14초 |
| B 포근이 | 6초간 회복 구역 생성. 0.5초마다 필드 캐릭터 최대 체력의 2.5% 회복 | 22초 |
| C 느릿이 | 가까운 범위에 6초간 슬로우 장판 생성 (이동 속도 -50%) | 16초 |
| D 든든이 | 조준 방향에 6초간 방벽 생성. 적 투사체 차단 + 적 진로 방해 | 18초 |

### 6.1 펫 디자인

펫은 모두 같은 **베이스 바디**(작고 둥근 유령: 공 모양 몸, 짧은 팔, 발 무늬, 유령 꼬리)에 스킬에 맞는 의상과 소품을 입혀 만든다. 포근이가 기준이다.

| 펫 | 콘셉트 | 머리 장식 | 소품 | 대표색 | 스킬과의 연결 |
| --- | --- | --- | --- | --- | --- |
| A 펑이 | 꼬마 폭파병 | 고글 달린 가죽 비행모 | 둥근 폭탄 (심지에 파란 불꽃), 파란 목도리 | 파랑 | 폭탄을 들고 달려가 터진다 |
| B 포근이 | 역병 의사 | 깃털 꽂은 실크해트, 새 가면 | 지팡이, 청록 불꽃의 등불 | 청록 | 치료사 → 회복 구역 |
| C 느릿이 | 졸린 모래시계지기 | 길게 늘어진 잠옷 모자 | 모래시계, 긴 줄에 매달린 회중시계 | 보라 | 시간을 늦춘다 → 슬로우 장판 |
| D 든든이 | 꼬마 방패기사 | 주황 깃이 달린 투구 | 주황 문양이 빛나는 방패, 짧은 망토 | 주황 | 방패 → 방벽 |

- **규칙**: 큰 머리 장식 하나 + 소품 한두 개. 그중 하나는 대표색으로 빛나고, 유령 꼬리도 대표색이다. 대표색은 펫 스킬 이펙트의 색(pets.csv 의 color)과 같다.
- **그림체**: 포근이의 원화를 기준으로 맞춘다. 면마다 단색에 가까운 손채색, 가늘고 거친 붓 외곽선, 금속 광택이나 잔 무늬 같은 묘사는 넣지 않는다.
- **크기감**: 몸은 전체 키의 3분의 1쯤인 작은 공 하나이고, 머리 장식이 크고 소품은 가늘게 밖으로 뻗는다. 게임에서는 몸(공)의 크기가 서로 비슷해 보이도록 펫마다 전체 키를 따로 정한다 (subjects.csv 의 height).
- 새 펫 3마리는 지금 정지 그림이다 (게임에서는 위아래로 떠 있는 움직임만 코드로 준다). 대기·시전 동작은 디자인이 확정되면 포근이처럼 영상으로 만든다.

- 펫 피해는 팀 3명의 평균 공격력을 기준으로 한다.
- 펫 성장은 시즌 스킬의 "펫" 분류로 이루어진다 (7.4절).

### 7.1 시즌 구조

- 시즌마다 메인 괴담 테마 1개, 테마에 맞춘 섹터 맵, 시즌 스킬, 시즌 장비, 보스를 가진다.

| 섹터 | 구성 | 클리어 후 |
| --- | --- | --- |
| 1 | 일반 섹터 (소형 위주, 학습 구간) | 경로 선택 |
| 2 | 일반 섹터 | 경로 선택 |
| 3 | 일반 섹터 + 출구에 중형 1체 | **체크포인트 캠프 1** → 경로 선택 |

### 7.2 섹터 맵

**구조**

- **맵 디자인은 고정이다.** 섹터마다 지형(벽, 건물, 구역, 통로)을 맵 파일로 만들어 둔다.
- **입장할 때마다 오브젝트가 무작위로 배치된다.** 엄폐 오브젝트(상자, 차량, 자판기, 화단), 몬스터 무리, 수색 오브젝트, NPC의 위치가 달라진다.
- 시작 구역에서 출구 구역까지 굽은 주 경로 (6~8 구역) + 막다른 가지 구역 2~4개로 디자인한다.
- 구역 사이는 좁은 골목 입구일 수도, 벽 없이 트인 광장일 수도 있다.
- 오브젝트와 벽은 이동과 투사체를 모두 막는다. 엄폐물로 쓸 수 있다.
- 맵 크기 기준: 가로 50칸 × 세로 32칸 (1칸 = 캐릭터 2명 폭). 화면에는 약 17 × 9칸이 보인다.

**무작위 배치 규칙**

무작위 배치가 진행을 막지 않도록 아래 규칙을 지킨다.

| 규칙 | 내용 |
| --- | --- |
| 통로 보장 | 맵 파일에 "통로"로 지정한 칸(주 동선, 폭 2칸 이상)에는 엄폐 오브젝트를 놓지 않는다 |
| 배치 가능 칸 | 엄폐 오브젝트는 "바닥" 칸에만 놓인다. 시작·출구·무리·수색·NPC 위치와 그 주변 1칸은 비운다 |
| 간격 | 오브젝트 덩어리 사이는 최소 1칸을 띄워 캐릭터가 지나갈 틈을 남긴다 |
| 밀도 | 맵별 밀도 값(바닥 칸 대비 %)으로 오브젝트 양을 조절한다 |
| 도달 검증 | 배치 후 시작 지점에서 출구와 모든 무리·수색 오브젝트·NPC까지 걸어갈 수 있는지 검사하고, 길을 막는 오브젝트는 제거한다 |
| 후보 위치 | 무리, 수색 오브젝트, NPC는 맵 파일에 표시한 후보 위치 중 일부를 뽑아 쓴다. 출구 수호 무리는 항상 같은 자리다 |
| 최소 거리 | 무리는 시작 지점에서 일정 거리 이상, 서로도 일정 거리 이상 떨어진 후보만 뽑는다 |

**배치 요소**

| 요소 | 규칙 |
| --- | --- |
| 몬스터 무리 | 섹터당 4~6무리. 주 경로와 가지 구역에 배치. 가까이 가거나 공격하면 무리 전체가 반응 |
| 출구 수호 무리 | 출구 구역의 무리. 처치해야 출구가 열린다 |
| 보상 상자 | 무리를 몇 개 전멸시킬 때마다 하나씩, 마지막에 전멸시킨 자리에 생긴다 (섹터마다 수가 정해져 있다. 7.3절). 다가가 상호작용 버튼을 누르면 3택 1 선택 |
| 수색 오브젝트 | 섹터당 4~6개. 다가가 상호작용 버튼을 누르면 수색을 시작하고, 0.8초 동안 근처에 머무르면 보상을 얻는다. 벗어나면 취소된다 |
| NPC | 섹터당 0~1명 (약 60% 확률). 다가가 상호작용 버튼을 누르면 랜덤 이벤트 |
| 출구 | 수호 무리 처치 후 활성화. 다가가 상호작용 버튼을 누르면 섹터 클리어 |

**수색 오브젝트 종류**

| 오브젝트 | 보상 |
| --- | --- |
| 보급 상자 | 괴담 조각 (재화) |
| 구급 상자 | 팀 전원 체력 회복 |
| 괴담의 잔재 | 팀 공격력 +3% / 최대 체력 +4% / 치명타 확률 +2% 중 하나가 무작위로 오른다. 런이 끝날 때까지 유지 |
| 봉인 상자 | 열면 괴이 무리가 소환된다. 처치하면 희귀 이상 보상 상자 |

**퀘스트 (HUD ⑩)**

- 주 목표: 출구를 지키는 괴이 처치 → 출구로 이동
- 보조 목표: 괴이 무리 처치 n / m (다음 보상 상자까지 남은 무리 수가 함께 적힌다), 오브젝트 수색 n / m

모든 무리를 잡을 필요는 없다. 가지 구역까지 탐험할수록 보상이 늘고 위험과 시간도 늘어난다.

### 7.3 보상 — 업그레이드 선택

**발생 시점**

| 시점 | 내용 |
| --- | --- |
| 무리 처치 | 무리를 몇 개 처치할 때마다 보상 상자가 하나 나온다. 다가가면 즉시 3택 1 |
| 섹터 클리어 | 출구 진입 시 3택 1을 1회 추가 |
| 봉인 상자 무리, 난입한 괴이 처치 | 반드시 보상 상자 하나 (희귀 이상 / 영웅 이상) |

**보상 상자의 박자** — 무리를 처치할 때마다 상자가 나오면 선택지가 너무 자주 뜬다. 그래서 섹터마다 "그 섹터의 무리가 주는 상자 수"를 정해 두고 (`sectors.csv` 의 `chests`), 그 수만큼만 고르게 나눠 준다.

- 무리 8개에 상자 4개면 2·4·6·8번째 무리에서, 무리 9개에 상자 4개면 3·5·7·9번째에서 나온다. 마지막 무리를 처치하면 마지막 상자가 나온다.
- 상자의 품질은 지난 상자 뒤로 처치한 무리 가운데 가장 높은 것을 따른다 (정예 무리가 하나라도 끼어 있었으면 희귀 이상).
- 상자가 나오지 않은 무리를 처치하면 그 자리에 "보상 상자까지 무리 n"이 뜨고, HUD 의 퀘스트 칸에도 남은 수가 적힌다.
- 출구 수호 무리는 상자를 남기지 않는다. 출구에서 받는 클리어 보상이 그 보상이다 (예전에는 상자와 클리어 보상을 잇달아 골랐다).
- 봉인 상자에서 나온 무리와 난입한 괴이는 이 박자와 상관없이 언제나 상자를 남긴다.
- `chests` 를 비운 섹터는 무리마다 상자가 나온다.

| 시즌 | 섹터별 무리 수 | 섹터별 상자 수 |
| --- | --- | --- |
| 시즌 1 | 2 · 3 · 3 · 4 · 4 · 4 · 4 · 5 | 1 · 1 · 1 · 1 · 1 · 1 · 1 · 1 |
| 시즌 2 (마름모 판 포함) | 8 · 9 · 4 · 4 · 5 | 4 · 4 · 2 · 2 · 2 |

**선택지가 뜨는 횟수** — 시즌 하나를 끝낼 때까지 고르는 선택지는 모두 30~35번쯤으로 잡는다. 아래는 전부 훑었을 때(무리를 모두 처치하고, 수색 오브젝트를 모두 열고, NPC에게 모두 말을 걸었을 때)의 평균이다. 검사(`tests/choices.test.ts`)가 이 합계가 30~36 안에 있는지 본다.

| 종류 | 시즌 1 (섹터 8 + 보스) | 시즌 2 (섹터 5 + 보스) | 예전 (시즌 1 / 시즌 2) |
| --- | --- | --- | --- |
| 3택 1 · 무리의 보상 상자 | 8 | 14 | 37 / 35 (출구 수호 무리 포함) |
| 3택 1 · 섹터 클리어 | 8 | 5 | 8 / 5 |
| 3택 1 · 봉인 상자, 돌발 사건, 제단 | 4.9 | 3.8 | 4.7 / 3.6 |
| 경로 선택 | 7 | 4 | 7 / 4 |
| NPC 이벤트 | 4.6 | 3.6 | 4.6 / 3.6 |
| 수상한 보따리 | 2.8 | 2.7 | 6.6 / 6.5 |
| **합계** | **35** | **33** | 68 / 58 |

- 세는 것: 여러 선택지 가운데 하나를 고르는 창. 캠프와 상점(들르는 곳), 귀중품을 얻었다는 알림은 세지 않는다.
- 수상한 보따리는 수색 오브젝트 가운데 나오는 비중을 낮췄다 (`objects.csv` 의 weight 22 → 8). 가방이 4칸인데 한 판에 예닐곱 개가 나와 버릴 것을 고르는 창까지 자주 떴다.
- 3택 1로 받는 보상이 시즌 1은 50번쯤에서 21번쯤으로, 시즌 2는 44번쯤에서 23번쯤으로 줄었다. 그만큼 팀이 덜 자라므로 몬스터의 강화 폭과 보스의 체력을 낮췄다 (8절, 12절).

| 선택지 | 내용 | 구분 |
| --- | --- | --- |
| 장비 | 각 캐릭터의 장비 슬롯에 장착. 장비마다 장비 스킬 1개 보유 | 시즌 장비: 무기 / 방어구 / 악세서리·심볼 |
| 스킬 성장 | 캐릭터의 스킬 성장 분기 또는 추가 스킬 | 고유 스킬 / 시즌 업그레이드 스킬 / 펫 스킬 |
| 장비 교체 | 장비를 교체하면 기존 장비는 컨텐츠 재화로 환산 | |

- 3택 1은 보통 고유 스킬 1 + 시즌 스킬 1 + 장비 1로 구성한다. 건너뛰면 괴담 조각을 받는다.
- 고유 스킬은 현재 팀에 편성된 캐릭터의 것만 나온다.
- 선택지 품질은 무리 등급과 섹터 위험 등급에 따라 올라간다.

**컨텐츠 재화**: 괴담 조각. 런 안에서만 쓰이고 런이 끝나면 사라진다.

### 7.4 시즌 스킬 (시즌 1)

팀 전체, 포지션 단위, 펫 단위로 성장시키는 시즌 특화 선택지다. 괄호는 최대 레벨.

| 분류 | 스킬 | 효과 |
| --- | --- | --- |
| 팀 | 그믐의 힘 (5) | 팀 공격력 +8% |

### 7.5 시즌 장비

- 캐릭터마다 슬롯 3개: 무기 / 방어구 / 악세서리·심볼.
- 장비 1개 = **장비 스킬 1개 + 능력치 옵션**.
- 장비 선택지를 고르면 장착할 캐릭터를 지정한다. 이미 장착한 슬롯이면 기존 장비는 괴담 조각으로 환산된다.

#### 장비 스킬 원칙

장비 스킬은 캐릭터의 스킬(기본 공격 / 액티브 / 궁극기 / 패시브 / 고유 성장)과 상관없이 장비 자체로 작동한다.
어떤 캐릭터가 착용해도 같은 효과를 낸다. 슬롯이 스킬의 성격과 발동 계기를 정한다.

| 슬롯 | 성격 | 발동 계기 |
| --- | --- | --- |
| 무기 | 공격적 | 착용 캐릭터가 공격할 때 — 공격 사용 / 적중 / 치명타 / 처치 |
| 방어구 | 방어적 | 착용 캐릭터가 맞을 때 — 피격 / 체력 저하 / 치명적 피해 |
| 악세서리·심볼 | 유틸 | 전투 흐름과 탐험 — 교체 / 회피 / 스킬 사용 / 수색 / 상시 |

- **발동 주체**: 착용 캐릭터가 필드에 있을 때만 발동한다. "팀 공통" 표시가 있는 악세서리 스킬은 착용 캐릭터가 오프 필드여도 적용된다.
- **피해 규칙**: 장비 스킬 피해 = 착용 캐릭터 공격력 × 장비 스킬 배율 × 약점 보정.
  치명타가 발생하지 않고, 캐릭터 고유 성장과 포지션 시즌 스킬의 피해 보정을 받지 않는다.
  장비 스킬의 피해는 다른 장비 스킬을 다시 발동시키지 않는다.
- **발동 제한**: 발동형 스킬은 자체 확률 또는 자체 쿨타임을 가진다.
- **스킬 레벨**: 장비의 희귀도가 장비 스킬 레벨을 정한다. 아래 스킬 표에서 굵게 표시한 수치에 레벨 배율이 곱해진다.

| 희귀도 | 장비 스킬 레벨 | 능력치 옵션 수 | 환산 재화 |
| --- | --- | --- | --- |
| 일반 | Lv1 (기준 수치) | 1 | 15 |
| 희귀 | Lv2 (×1.3) | 2 | 30 |
| 영웅 | Lv3 (×1.6) | 2 (수치 높음) | 60 |
| 전설 | Lv4 (×2.0) | 3 | 100 |

### 7.7 경로 선택

섹터를 클리어하면 다음 섹터의 경로를 고른다. 경로가 다음 맵 몬스터의 등급과 보상을 정한다.

| 경로 | 몬스터 | 보상 |
| --- | --- | --- |
| 일반 경로 | 일반 등급 위주 | 기본 |
| 정예 경로 | 무리당 몬스터 수 증가, 절반의 무리에 정예 포함, 출구에 중형 | 희귀 확률 상승, 괴담 조각 +50% |
| 특급 경로 | 모든 무리에 정예 포함, 특급 몬스터 출현, 능력치 +25% | 클리어 보상 영웅 이상 보장, 괴담 조각 +100% |
| 보너스 맵 (가끔 등장) | 몬스터 없음 또는 소수 | 보급 창고: 수색 오브젝트 다수 + 보상 상자 1개. 이후 원래 다음 섹터로 진행 |

- 매번 2~3개가 제시된다. 보너스 맵은 약 35% 확률로 선택지에 추가된다.
- 특급 경로는 섹터 3을 클리어한 뒤부터 나온다.
- 섹터 클리어 보상의 품질은 그 섹터에 들어올 때 고른 경로를 따른다.
- 위험한 경로를 고를수록 팀 점수도 올라간다 (7.10절).

**가려진 선택지** — 매번 같은 선택지가 같은 조건으로 나오면 고민할 것이 없으므로, 절반쯤(55%)의 확률로 "가려진 길"이 하나 섞여 나온다.

- 가려진 길은 **위험(일반 / 정예 / 특급)과 보상(일반 / 희귀 이상 / 영웅 이상)이 서로 따로 정해진다.** 약한 무리에 영웅 보상일 수도, 특급 괴이에 평범한 보상일 수도 있다.
- 그 둘 가운데 하나(각 절반) 또는 둘 다(25%)가 "?"로 가려진 채 카드에 나온다. 가려진 것은 그 섹터에 들어간 직후 화면에 밝혀진다.
- 위험한 경로가 둘(정예, 특급) 나와 있으면 가려진 길이 그중 하나의 자리를 차지하고, 하나뿐이면 카드가 한 장 더 놓인다. **일반 경로는 언제나 보이는 채로 남는다** (안전한 선택은 늘 있다).
- 가려진 길을 고르면 실제 위험의 점수에 더해 팀 점수 +15를 받는다.
- 장비 스킬 "초록 안경"(시즌 2)이 팀에 있으면 위험이 보이고, 희귀 등급부터는 보상도 보인다.
- 비중은 `routes.csv` 의 `hidden` 열(실제 위험)과 `params.csv` 의 `route.hidden*` 에 있다.

**돌발 사건** — 일반 섹터에 들어갈 때 30% 확률로 하나가 일어난다. 무엇이 일어났는지는 들어간 직후 화면과 퀘스트 칸에 알린다.

| 사건 | 내용 |
| --- | --- |
| 난입 | 들어온 지 6초 뒤 특급 괴이(그 시즌의 중형)가 파티 근처에 나타난다. 쓰러뜨리면 영웅 이상 보상 상자 |
| 떨어진 보급품 | 섹터 어딘가에 보상 상자(희귀 이상)가 하나 더 놓인다 |
| 떠돌이 상인 | 섹터 어딘가에 상인이 자리를 편다. 말을 걸면 바로 상점이 열린다 |
| 몰려든 무리 | 무리마다 몬스터가 1마리씩 늘어난다. 이 섹터의 괴담 조각 +50% |
| 운수 좋은 날 | 이 섹터의 클리어 보상 품질이 한 단계 오른다 |

- 보스 섹터와 보너스 맵에는 일어나지 않는다. 두 시즌 모두에 적용된다.
- 사건의 종류와 비중은 `surprises.csv`, 일어날 확률은 `params.csv` 의 `event.chance`.

| 섹터 클리어 후 보상·경로 선택을 마침 | 자동 저장 |

| 섹터 도중 게임을 닫음 | 로비의 "이어하기"로 그 섹터 처음부터 다시 시작. 오브젝트 배치는 다시 뽑는다 |
| 전멸 / 런 포기 / 탈출 / 보스 격파 | 저장된 런 삭제 |

섹터 도중 닫으면 그 섹터를 다시 할 수 있어 전멸 규칙을 피하는 수단이 될 수 있다. 프로토타입에서는 허용한다.

### 7.12 귀중품과 가방

런 안의 성장(스킬, 장비)과 별개로, **던전 밖으로 들고 나가야 값어치가 생기는 물건**을 줍는다. 익스트랙션의 긴장감을 만드는 장치다.

| 항목 | 내용 |
| --- | --- |
| 귀중품 | 13종, 등급 4단계 (평범 / 희귀 / 진귀 / 전설). 등급이 높을수록 은화 가치가 크다 (24 ~ 580) |
| 가방 | 4칸. 가득 찬 상태에서 새것을 얻으면 가방의 물건과 새 물건 가운데 하나를 골라 버린다 |
| 교환 | 캠프에서 탈출하거나 보스를 쓰러뜨려 런을 끝내는 순간, 가방의 귀중품이 전부 은화로 바뀐다 |
| 잃는 경우 | 전멸하거나 조사를 포기하면 가방째 잃는다 |
| 은화 | 던전 밖 재화. 기기에 쌓이고 로비에 표시된다. 쓰는 곳은 아직 없다 |

| 곳 | 내용 |

### 7.13 시즌 2 — "소원을 삼키는 나라"

오래된 동화 "오즈의 마법사"를 무대에 올리던 극장이 괴담이 된 곳. 안개 낀 꽃길과 세트장 숲을 지나, 무너진 극장의 무대에서 막을 내리지 못한 주연 "부서져 가는 마녀 인형"을 토벌한다.
로비에서 시즌을 고른다 (마지막으로 고른 시즌을 기억한다). 시즌 1은 그대로 남아 있다.

- **저작권**: 1939년 영화 고유의 디자인과 음악은 쓰지 않는다 (초록 피부의 마녀, 루비 구두, 영화의 의상·노래 등). 원작 동화에 나오는 소재(노란 벽돌길, 은 구두, 초록 안경, 황금 모자, 양철 나무꾼의 깔때기 모자)와 "무대 소품이 된 동화"라는 이 게임의 설정으로 그린다.

### 7.14 마름모 화면 (시험판)

맵에 입체감을 더 주려고, 시즌 2를 마름모(아이소메트릭 2:1) 화면으로 다시 만들어 본 판이다. 로비의 시즌 카드에 "시즌 2 · 마름모"로 따로 들어가 있고, 기존 시즌 1·2는 그대로다.

- **같은 것**: 캐릭터, 몬스터와 무리 구성, 보스, 시즌 스킬, 장비, 귀중품, 경로·캠프·보상 규칙, 섹터의 수와 순서(꽃길 → 숲 → 극장 셋 → 보스, 보너스 맵). 표에서는 시즌 3으로 적고 `seasons.csv` 의 base 에 2를 적어 시즌 2의 내용을 쓴다.
- **다른 것**: 맵의 지형(새로 짰다)과 보는 방식.
- **보는 방식**: 맵을 45도 돌려 비스듬히 내려다본다. 맵의 +x 가 화면 오른쪽 아래로, +y 가 왼쪽 아래로 가고, 네모 칸이 가로 2 : 세로 1 의 마름모로 보인다. 캐릭터와 몬스터의 그림은 그대로 쓴다 (세워 그린다).
- **조작**: 방향 패드는 화면 기준이다. 패드를 민 방향 그대로 화면에서 움직인다. 길(바닥 격자의 줄)은 화면에서 가로 2 : 세로 1 로 기울어 있으므로(약 27도), 그 각도로 밀면 길을 따라 걷는다. 화면에서 옆으로 걷는 빠르기는 기존과 같고, 위아래로는 절반으로 보인다 (바닥이 그만큼 눌려 보이기 때문이다. 규칙에서의 빠르기는 어느 방향이든 같다). 키보드는 8방향뿐이라 대각선이 길과 나란하도록 45도 돌려서 받는다.
- **범위 표시**: 원형 범위와 공격 예고는 바닥처럼 눌려 타원으로 보인다. 판정은 기존과 같다.
- **벽의 높이**: 벽을 높이 세우면 그 뒤(화면 위쪽)의 것을 가린다. 그래서 뒤쪽에 걸어 다니는 바닥이 없는 벽만 높이 세우고(방의 뒷벽), 뒤쪽 가까이에 바닥이 있는 벽은 낮게 잘라 바닥 둘레의 테두리만 남긴다. 캐릭터와 몬스터는 벽에 가려지지 않는다. 엄폐 오브젝트가 필드 캐릭터를 가리면 그 오브젝트를 비쳐 보이게 한다.
- **맵의 모양**: 길이 화면 왼쪽에서 오른쪽으로 지그재그로 나아간다 (맵에서는 동쪽과 북쪽을 번갈아 가는 계단 모양). 이렇게 놓으면 길의 뒤쪽에 언제나 높은 벽이 서고, 그 위로 나무·오두막·풍차·조명탑 같은 구조물이 배경처럼 늘어선다. 곁방(수색 오브젝트가 있는 막다른 방)은 길의 앞이나 뒤로 낸다.
- **그림**: 바닥·노란 벽돌길·바닥 장식·엄폐 오브젝트·상호작용 오브젝트는 기존 그림을 쓴다. 벽 위의 구조물만 마름모 각도로 새로 그렸다 (세트마다 9종).
- **남은 일 (해 보고 정할 것)**: 엄폐 오브젝트를 마름모 각도로 다시 그릴지, 도전 모드의 전투장도 마름모로 만들지, 화면의 확대 정도.

### 7.15 화면 분위기 (어둡게 물들이기)

괴담을 조사하는 게임인데 맵(특히 시즌 2의 꽃밭)이 너무 밝고 발랄해 보여서, 맵 전체를 셰이더로 어둡고 빛바래게 물들인다.

- **필드 캐릭터 둘레만 밝다**: 손전등을 든 것처럼 캐릭터 둘레는 밝고, 멀어질수록 어두워진다. 화면 가장자리는 더 어둡다.
- **색**: 채도를 낮추고, 어두운 곳에는 차가운 색(푸른빛, 청록빛, 보랏빛)을 입힌다. 캐릭터 둘레의 빛은 조금 따뜻한 색이다.
- **밝은 것은 덜 어두워진다**: 불빛과 빛나는 장식은 어둠 속에서 도드라진다.
- **전투 표시는 어두워지지 않는다**: 타격 이펙트, 피해 숫자, 체력 막대, 조준 표시는 셰이더 밖에서 그린다. 몬스터와 공격 예고는 맵과 함께 어두워지지만, 곱해서 어둡게 하므로 바닥과의 밝기 차이는 그대로 남는다.
- **맵 그림 세트마다 따로 정한다** (`data/moods.csv`): 꽃밭은 해 질 녘처럼, 숲은 더 어둡고 청록빛으로, 극장은 조명이 닿는 곳만 따뜻하게. 시즌 1의 골목은 원래 어두워서 가장자리만 살짝 어둡게 했다.
- **세기**: `params.csv` 의 `mood.strength` (%). 0이면 끄고, 100이면 표에 적힌 그대로다. 그 사이는 고르게 섞인다.
- 기존 화면과 마름모 화면, 도전 모드의 전투장에 모두 걸린다 (그 전투장의 맵 그림 세트를 따른다).

| 세트 | 채도 | 먼 곳의 밝기 | 어두운 곳의 색 |
| --- | --- | --- | --- |
| alley (시즌 1 골목) | 92% | 72% | 푸른빛 |
| oz_field (꽃밭) | 64% | 46% | 푸른 보랏빛 |
| oz_forest (숲) | 66% | 46% | 청록빛 |
| oz_stage (극장) | 80% | 50% | 보랏빛 |

### 8.4 몬스터 애니 리소스

대기 (Idle) · 이동 (Move) · 피격 (Hit) · 스턴 (Stun) · 죽음 (Death) · 기본 공격 (MonsterAttack) · 스킬 (Pattern) · 보스 전용: 필살기 (Finale), 페이즈 전환 (Phase)

- **공격 동작은 예고 시간에 맞춰 재생한다.** 규칙이 공격을 시작할 때 동작의 전체 길이와 타격 시점을 함께 알려 주고, 표시부는 그림의 타격 프레임(준비가 끝나고 내지르는 순간)이 예고가 끝나는 순간에 오도록 앞부분과 뒷부분을 따로 늘이거나 줄인다. 예고가 긴 양철 나무꾼은 도끼를 천천히 들어 올리고, 예고가 짧은 늑대는 재빨리 웅크린다. 예고 표시(바닥의 붉은 범위)와 몸짓이 같은 순간에 끝난다.
- **피격**: 대기·이동 중에 맞으면 0.28초 동안 움찔한다. 공격을 준비하거나 공격하는 중에는 동작을 끊지 않는다 (예고와 어긋나 보이지 않게). 보스는 움찔하지 않는다.
- **스턴**: 전용 그림이 없으면 피격 그림 위에서 몸을 떨며 푸르게 물든다.
- **죽음**: 쓰러지는 동작을 0.5초 동안 보여 주고 0.25초에 걸쳐 사라진다 (`enemy.deathTime` 0.75초). 보스는 섹터가 끝날 때까지(1.6초) 쓰러진 채로 남는다 (`enemy.bossDeathTime`).
- 없는 동작은 가까운 동작으로 대신한다 (Finale·Phase → Pattern → MonsterAttack → Idle). 그림이 하나도 없는 공격 준비는 몸이 부풀며 붉어지는 것으로 보여 준다.

## 9. 파티덱 컨텐츠 (도전 모드)

저장된 파티덱으로 도전한다. 덱의 빌드는 고정이며 컨텐츠 안에서는 성장하지 않는다.

**들어가는 순서**: 로비의 "도전 모드" → ① 컨텐츠와 난이도를 고른다 → ② 출전할 조사 팀을 고른다 → 진입.

- ① 화면에는 컨텐츠마다 난이도, 권장 팀 점수, 모든 조사 팀을 통틀어 가장 좋은 기록이 보인다.
- ② 화면에는 저장된 조사 팀과 테스트용 조사 팀이 나온다. 팀마다 팀 점수, 만든 시즌, 고른 도전에서의 그 팀의 기록이 보이고, 권장 팀 점수에 못 미치면 "권장 점수 미달"이 붙는다 (출전은 할 수 있다). "보기"로 빌드를 확인한다.
- 결과 화면에서 "다시 도전"(같은 팀, 같은 도전) 또는 "도전 모드로"를 고른다. 도전을 포기해도 도전 모드로 돌아온다.
- 어느 시즌에서 만든 팀이든 모든 컨텐츠에 출전할 수 있다. 빌드(시즌 스킬과 장비 포함)는 만든 그대로 쓰이고, 전투장과 몬스터만 컨텐츠의 시즌을 따른다.

| 컨텐츠 | 시즌 | 내용 |
| --- | --- | --- |
| 특급 괴이 토벌 · 그믐의 우산 | 1 | 9.1절. 시즌 1 보스의 전투장 |
| 특급 괴이 토벌 · 부서져 가는 마녀 인형 | 2 | 9.1절. 시즌 2 보스의 무대. 규칙과 난이도 수치는 시즌 1 토벌과 같다 |

### 11.1 그래픽 리소스 제작 방식

| 항목 | 내용 |
| --- | --- |
| 캐릭터 형태 | 2.5~3등신 SD 캐릭터. 전투는 SD 캐릭터로 진행한다 (전신 디자인은 원화 기준 자료) |
| 표현 | 스프라이트 애니메이션 |
| 이미지 제작 | 게임에 들어가는 이미지 리소스는 전부 Codex 이미지 생성 도구로 만든다 (캐릭터, 몬스터, 맵 타일, 오브젝트, 아이콘) |
| 애니메이션 제작 | Seedance 2.5 API로 동작 영상을 만들고, 영상에서 프레임을 뽑아 스프라이트 시트로 변환해 게임에 적용한다 |
| 프로토타입 단계 | 플레이스홀더. 캐릭터는 머리색·의상색·무기로 구분되는 도형 SD. 스프라이트 시트가 등록된 캐릭터는 스프라이트로 그린다 |

플레이스홀더에서 실제 리소스로 넘어갈 때 다시 만들지 않도록 다음을 지킨다.

- 캐릭터·몬스터의 표시부는 교체할 수 있는 부품으로 분리한다. 전투 규칙 코드는 "어떤 상태(대기 / 이동 / 기본 공격 …)인지, 어느 방향을 보는지"만 알려 주고, 그것을 도형으로 그릴지 스프라이트로 그릴지는 표시부가 정한다.
- 상태 이름은 5.4절(캐릭터)과 8.4절(몬스터)의 목록을 그대로 쓴다. 스프라이트 시트도 이 이름으로 묶는다.
- 타격 타이밍(선딜레이, 판정 시점, 후딜레이)은 수치 테이블에 두어, 나중에 애니메이션 길이에 맞춰 조정할 수 있게 한다.

#### 제작 과정

원화 한 장에서 게임용 스프라이트까지 네 단계다. 실행 방법은 README의 "스프라이트 제작" 참고.

| 단계 | 내용 | 규칙 |
| --- | --- | --- |
| 1. 기본 이미지 | Codex로 원화를 2.5등신 SD의 대기 자세로 그린다. 방향마다 1장 | 정사각형, 단색 배경(캐릭터에 없는 색: 초록 / 자홍 / 파랑), 캐릭터 키는 화면 높이의 45~55%. 여백은 무기를 휘두를 공간이다 |
| 2. 동작 영상 | 기본 이미지를 첫 프레임으로 Seedance가 동작 영상을 만든다 | 카메라 고정, 배경 단색 유지. 공격 동작은 무기를 따라가는 흰 검기만 허용하고, 그 밖의 이펙트는 넣지 않는다(게임이 따로 그린다). 반복 동작과 제자리로 돌아오는 동작은 끝 프레임도 기본 이미지로 지정한다. 단발 동작은 기본 이미지를 70% 크기로 줄여 넣어, 휘두른 무기가 화면 밖으로 잘리지 않게 여백을 둔다 |
| 3. 프레임 | 배경색을 빼고, 쓸 구간에서 프레임을 고른다 | 반복 동작은 한 주기를 같은 간격으로 고른다. 단발 동작은 실제로 움직이는 구간에서, 움직임이 빠른 곳일수록 촘촘하게 고른다. 자동으로 잡은 구간이 어색하면 초 단위로 직접 지정한다 |
| 4. 시트 | 한 캐릭터의 모든 동작을 시트 이미지에 모은다 | 시트 한 장은 2048px 이하. 프레임은 여백을 잘라 넣는다 |

- **크기와 위치의 기준**: 모든 동작 영상이 같은 기본 이미지에서 시작하므로, 기본 이미지에서 잰 발 위치와 키를 모든 프레임에 똑같이 적용한다. 그래서 동작이 바뀌어도 캐릭터가 튀거나 크기가 달라지지 않는다.
- **방향**: 화면 기준 앞쪽 사선(SE) 한 방향만 만들고, 좌우 반전으로 왼쪽·오른쪽을 표현한다. 위쪽으로 움직일 때도 앞모습이 나온다. 반전하면 무기 든 손과 머리 장식의 좌우가 바뀐다. 표의 방향 칸에 방향을 더 적으면 그 방향 그림도 만들 수 있다 (비용이 방향 수만큼 늘어난다).
- **없는 동작**: 그림이 아직 없는 동작은 가까운 동작으로 대신한다 (이동 → 대기, 액티브 → 기본 공격, 궁극기 → 액티브, 회피 → 이동 등). 그래서 대기 동작 하나만 있어도 게임에 넣을 수 있고, 동작을 하나씩 늘려 가면 된다.
- **타이밍**: 단발 동작은 규칙이 정한 동작 길이에 맞춰 재생한다. 프레임마다 원래 영상에서의 시점을 기억해 두어, 준비 자세는 천천히, 휘두르는 순간은 빠르게 넘어가는 원래의 빠르기 변화가 그대로 나온다. 공격 동작은 가장 빠르게 움직이는 순간을 "타격 지점"으로 자동으로 잡아, 그 프레임이 규칙상의 타격 시점에 오도록 맞춘다 (표에 숫자를 적으면 그 값을 쓴다).
- **기본 공격 연속기**: `BasicAttack1`, `BasicAttack2` … 처럼 단계별 동작을 만들면 연속기 순서대로 쓴다. 하나(`BasicAttack`)만 있으면 모든 단계에 그것을 쓴다. 에트나은 3연격에 맞춰 가로 베기 → 올려 베기 → 내려찍기 세 동작을 쓴다.
- **프레임 수**: 대기 96장(영상의 모든 프레임. 초당 24장으로 4초짜리 숨쉬기가 원래 빠르기대로 나온다), 이동 8장, 공격 12~16장. 영상은 초당 24장으로 만들어지고 그중 일부를 골라 쓰므로, 프레임 수는 표에서 바꾼 뒤 3·4단계만 다시 돌리면 된다 (영상을 다시 만들지 않으므로 비용이 들지 않는다).
- **빼는 구간**: 영상 모델은 쏘는 동작에 총구 화염·연기·폭발·날아가는 화살을 넣으려는 경향이 강하다. 그런 구간은 표에서 "뺄 구간"으로 적어 프레임에서 빼고, 발사 이펙트와 발사체는 게임이 대신 그린다. 빠진 자리가 곧 타격 지점이 된다 (카렌·라이·키온의 기본 공격).
- **무기 끝 위치**: 캐릭터마다 공격 자세의 그림에서 무기 끝이 어디인지(발밑 기준 앞쪽·위쪽 px)를 재서 `characters.csv` 의 muzzleX·muzzleY 에 적는다. 무기에서 쏘는 발사체는 여기서 출발해 0.16초에 걸쳐 판정 위치로 합류하고, 총구 이펙트도 여기서 터진다. 그림만 바뀌고 판정은 그대로다.
- **몬스터**: 순서는 캐릭터와 같다. 다른 점은 세 가지다. ① 기본 이미지에 잡힌 크기가 제각각이라(늑대는 화면의 30%, 보스는 80%) 영상의 첫 프레임에는 몸의 키가 정해진 범위에 들도록 키우거나 줄여 넣는다. 작게 넣으면 영상 모델이 동작 장면에서 확대 컷으로 넘어가 크기가 튄다. ② 움직임 설명을 몬스터마다 따로 적는다 (공용 설명으로는 허수아비와 늑대가 같은 몸짓을 하게 된다). ③ 죽음은 "쓰러져 가만히 있다"로 끝낸다. "연기로 흩어진다" 같은 반투명한 효과는 단색 배경에서 얼룩으로 남는다. 사라지는 것은 게임이 한다. 떠 있는 몬스터(원숭이)가 떨어져 쓰러지는 동작은 몸이 내려간 만큼 프레임을 올려, 제자리(그림자 위)에 내려앉게 한다.
- **표**: 만들 대상과 동작 목록, 영상·배경 제거 설정은 `data/art/` 의 표에서 고친다 (subjects.csv, clips.csv, settings.csv).

#### 맵 그림

맵은 영상 없이 Codex 이미지 생성만으로 만든다 (실행 방법은 README의 "맵 그림").

| 종류 | 내용 | 만드는 방식 |

| 지붕 · 벽 | 건물의 윗면과 앞면 | 이어 붙는 질감. 벽 앞면에는 창문·문·셔터·간판·벽보 같은 장식을 칸마다 정해진 규칙으로 붙인다 |
| 엄폐 오브젝트 | 나무 상자, 나무통, 드럼통, 쓰레기통, 자판기, 전봇대, 가로등, 소화전, 화단, 벤치, 가판대, 방수포 더미, 승용차, 트럭 등 21종 | 여러 물체를 한 장에 격자로 그려 받아 물체별로 잘라 쓴다 |

| 바닥 장식 | 맨홀, 배수구, 물웅덩이, 균열, 횡단보도, 신문지, 낙엽 등 9종 | 위와 같음. 칸 좌표로 자리가 정해져 같은 맵은 늘 같은 모습이다 |

- 엄폐 오브젝트는 종류와 차지하는 칸 수(가로×세로)가 규칙 쪽 배치와 맞아야 한다. 그림이 없는 종류는 도형으로 그려진다.
- 불이 켜진 창문·자판기·가로등·가판대 주변에는 빛이 번지게 해 밤 분위기를 낸다.
- **바닥에 맞춘다**: 오브젝트 시트를 생성할 때 바닥 질감을 기준 그림으로 함께 넘겨, 그림체(부드러운 채색, 가는 남색 외곽선)와 색(달 없는 밤의 채도 낮은 청회색)을 바닥에 맞춘다. 오브젝트는 바닥보다 조금만 밝게 그려 윤곽은 읽히되 튀지 않게 하고, 밝은 색은 불빛에만 쓴다. 상호작용 오브젝트는 그보다 조금 더 밝게 그리고 은은한 빛을 둔다. 확인용 그림(`art/scenery/preview.png`)도 실제 바닥 위에 늘어놓아 어울리는지 본다.
- **특정 나라의 요소를 넣지 않는다**: 글로벌 서비스이므로 장독·포장마차·평상·부적·석상처럼 한 나라에 고유한 물건은 쓰지 않고, 어느 도시에나 있을 물건으로 그린다. 배경 설정 문구(`scenery.theme`)에도 이 조건을 적어 둔다.
- 무엇을 그릴지는 `data/art/scenery_sheets.csv`(시트)와 `data/art/scenery.csv`(시트 안의 물체, 게임에서의 크기)에 적는다.
- **세트**: 한 가지 분위기의 맵 그림 한 벌을 세트라 부른다 (`data/art/scenery_sets.csv`). 세트마다 배경 설정 문구, 그림체·색 지시문, 지붕 가장자리 색, 맵 바깥 색을 따로 갖는다. 섹터가 어느 세트를 쓰는지는 `sectors.csv` 의 `scene` 열로 정한다.

| 세트 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| alley | 시즌 1 전체, 덱 컨텐츠 | 달 없는 밤의 구도심 골목 (위 표) |
| oz_field | 시즌 2 섹터 1 | 짓밟힌 꽃밭. 지붕 자리는 커다란 꽃과 잎의 덤불, 벽은 이끼 낀 돌담. 울타리·건초 더미·우물·수레·쓰러진 허수아비 |
| oz_forest | 시즌 2 섹터 2 | 세트장이 된 숲. 지붕 자리는 나무 꼭대기, 벽은 나무줄기와 합판 세트. 그루터기·통나무집 잔해·무대 조명·녹슨 양철 조각 |
| oz_stage | 시즌 2 섹터 3~6, 보너스 | 무너진 극장. 나무 무대 바닥, 붉은 막의 벽. 객석 의자·소품 상자·분장대·조명 |
| oz | (다른 세트에 포함) | 시즌 2 세 세트가 함께 쓰는 것: 상호작용 오브젝트, 포자 버섯, **서 있는 문**(출구. 잠겨 있으면 닫힌 문, 열리면 열린 문), **노란 벽돌길** 조각 |

#### 이펙트 그림

이펙트는 재료 두 가지를 섞어 쓴다 (실행 방법은 README의 "이펙트 그림").

| 재료 | 내용 | 만드는 방식 | 쓰는 곳 |
| --- | --- | --- | --- |
| 조각 | 그림 한 장짜리. 베기 궤적, 찌르기 줄기, 타격 섬광, 고리, 방사형 폭발, 연기, 빛기둥, 문양, 번개, 화살, 총알, 혼불, 균열 등 37종 | 여러 조각을 한 장에 격자로 그려 받아(Codex) 잘라 쓴다. 검은 바탕에 흰 빛으로 그려 받고, 밝기를 불투명도로 바꾼다 | 대부분의 이펙트. 게임이 크기·회전·투명도·색을 시간에 따라 움직인다 |
| 플립북 | 영상에서 뽑은 16장짜리 | 색이 들어간 첫 그림(Codex)에서 시작해 사라지는 영상(Seedance)을 만들고 프레임을 뽑는다 | 대표 궁극기 4종: 라이의 낙뢰, 에트나의 균열 분출, 라온의 유성 폭발, 로아의 혼령 폭발 |

- **색**: 조각은 흰색으로 저장하고 게임에서 캐릭터 색을 입힌다. 캐릭터 색은 옅은 파스텔이라 그대로 빛으로 겹치면 하얗게 날아가므로, 색상은 유지하고 채도를 올려 입힌다. 가장 밝은 부분만 따로 남긴 "흰 심지"를 위에 겹쳐, 가운데는 하얗게 타고 가장자리만 색이 돌게 한다.
- **이름으로 부른다**: 규칙 코드는 "라온의 지면 강타가 여기서 이 크기로 터졌다"처럼 무슨 일이 일어났는지만 알리고, 그것을 어떤 조각으로 어떻게 그릴지는 표시부의 이펙트 목록(`src/render/fxRecipes.ts`)이 정한다. 이펙트를 고쳐도 규칙 코드는 건드리지 않는다.
- **적용 범위**: 캐릭터 9명의 액티브·궁극기, 타격 섬광(무기 종류별 6가지, 치명타는 더 크게), 처치, 회피, 교체, 궁극기 시전, 총구 화염, 투사체(전격·화살·창·검기·총알·부적), 범위 효과(균열, 결계 문양, 진군의 기운), 설치물(포탑, 깃발).
- **코드로 남기는 것**: 적의 공격 예고(바닥의 원·선)는 판정 범위와 정확히 맞아야 하므로 지금처럼 코드로 그린다. 피해 숫자와 알림 글자도 코드다.
- **없을 때**: 이펙트 그림을 읽지 못하면 예전의 도형 이펙트가 나온다. 플립북이 없으면 그 첫 그림을 정지 조각으로 대신 쓴다.
- **표**: `data/art/fx_sheets.csv`(시트), `data/art/fx.csv`(조각과 게임에서의 크기), `data/art/fx_flips.csv`(플립북).

비용은 영상 한 편(1:1, 480p, 4초)에 Seedance 2.5 flash 기준 약 0.27달러다 (2.5 일반은 약 0.42달러). 캐릭터 한 명의 동작 7종을 만들면 약 1.9달러다 (기본 공격을 연속기 단계별로 나누면 단계 수만큼 늘어난다). 이펙트 조각과 맵·화면 그림은 이미지 생성이라 영상 요금이 들지 않는다.

수치는 코드에서 분리해 `data/` 폴더의 CSV 파일로 관리한다. 엑셀이나 구글 시트로 열어 고친 뒤 저장하면 게임에 반영된다.

| maps/*.txt | 섹터별 고정 맵 (문자 격자) |

- CSV는 UTF-8로 저장한다. 엑셀에서는 "CSV UTF-8 (쉼표로 분리)" 형식으로 저장해야 한글이 깨지지 않는다.
- 게임을 시작할 때 테이블을 검사해, 값이 빠졌거나 숫자가 아니면 어느 파일 몇 번째 줄인지 화면에 표시한다.

### 11.3 성능 (끊김과 느려짐)

궁극기를 쓸 때 화면이 느려지는 문제를 두 갈래로 다뤘다.

| 원인 | 대응 |
| --- | --- |
| 그림을 처음 그리는 순간 그래픽 메모리로 올리느라 끊긴다. 궁극기 전용 그림(플립북 시트)이나 캐릭터 시트의 둘째 장처럼 드물게 쓰는 그림에서 전투 한가운데 일어난다 | 그림을 읽자마자 미리 올려 둔다. 전투에 들어가기 전에 전부, 늦게 도착한 것은 한 프레임에 한 장씩 |
| 화면 라이브러리(PixiJS)가 1분 동안 그리지 않은 그림을 그래픽 메모리에서 내린다. 그래서 궁극기 그림이나 대기 중인 캐릭터의 시트가 다시 쓰일 때마다 또 끊긴다 | 자동 해제를 끈다. 그림은 팀이 바뀔 때 직접 정리한다 |
| 넓은 이펙트 여러 장을 반투명으로 겹쳐 칠한다. 화소 밀도가 높은 화면일수록 부담이 크다 | 화면의 내부 픽셀 수에 상한(params.csv 의 view.maxPixels)을 두고, 픽셀 수가 많은 화면에서는 계단 현상 줄이기(MSAA)를 끈다 |
| 같은 원인 (이펙트 쪽) | 넓은 조각(긴 변 300px 초과)은 흰 심지를 겹치지 않고 한 겹으로만 그린다. 라온·에트나 궁극기는 겹치는 장수를 줄였다 |

- 이펙트의 부담은 "이펙트가 화면을 몇 겹 덮는가"(이펙트 스프라이트의 화면 안 넓이 합 ÷ 화면 넓이)로 잰다. 기기와 무관하게 비교할 수 있다.
  고친 뒤 궁극기 9종 모두 최대 1.8겹 이하다 (라온 2.4 → 1.4겹, 에트나 2.3 → 1.5겹).
- 화면 분위기 셰이더(7.15절)는 맵을 한 번 따로 그린 뒤 화면 전체에 한 번 더 칠한다 (전체 화면 한 겹). 부담이 되는 기기가 있으면 `mood.strength` 를 0으로 두어 끌 수 있다.
- 실제 기기에서의 프레임 속도는 아직 재지 못했다. 폰 실기 테스트에서 확인한다.

### 11.4 소리

소리는 네 가지다. **효과음**(공격·타격·몬스터·화면 버튼), **배경 음악**(장소마다 한 곡이 끊김 없이 반복), **환경음**(음악 밑에 깔리는 바람·삐걱임), **징글**(클리어·전멸 같은 짧은 음악).

#### 언제 어떤 소리가 나는가

규칙 코드는 그림과 마찬가지로 "무슨 일이 일어났는지"만 알리고, 어떤 소리를 낼지는 표(`data/sound/cues.csv`)가 정한다.

- 이름으로 부르는 이펙트(`fx.play('raon.slam')`)는 같은 이름의 소리를 함께 낸다. 그림이 없는 일은 `fx.sound('hurt')` 로 알린다.
- **종류별 소리**: 일에 종류(무기 종류, 발사체 종류, 몬스터 id, 몬스터 크기)가 딸려 오면 표에서 "이름.종류" 줄을 먼저 찾고, 없으면 "이름" 줄을 쓴다. 대검으로 때리면 `hit.greatsword`, 표에 없는 무기는 `hit`.
- **같은 일이 한꺼번에 여러 번** 일어나도(한 번 휘둘러 다섯을 맞힘, 산탄 여섯 알) 소리는 한 번만 난다 (cooldown). 같은 소리가 기계처럼 되풀이되지 않게, 낼 때마다 높낮이를 조금 흩고(pitch) 여러 벌 만든 소리는 번갈아 낸다.
- **거리와 방향**: 필드 캐릭터에게서 320px 안의 소리는 그대로, 1100px 밖은 들리지 않고 그 사이는 고르게 줄어든다. 옆에서 난 소리는 그쪽 스피커로 치우친다 (최대 60%). 화면 밖에서 벌어지는 일이 작게 들린다.
- 한꺼번에 낼 수 있는 효과음은 24개까지다.

| 묶음 | 일 | 소리 |
| --- | --- | --- |
| 기본 공격 | 근접 무기를 휘두름 (맞지 않아도 난다) | 무기마다 다르다: 대검·쌍검·해머·깃창 (각 2벌) |
| | 발사체가 나감 | 발사체마다 다르다: 전격, 화살, 산탄, 총알, 부적, 검기, 큰 화살 |

#### 배경음

| 장소 | 음악 | 환경음 |
| --- | --- | --- |
| 로비·편성 | 차분하고 수상한 로파이 (96 BPM) | |
| 시즌 1 골목 | 긴장된 전자음 (128 BPM) | 밤 골목의 바람과 전깃줄 소리 |
| 시즌 1 보스 · 시즌 1 보스 토벌 · 괴이 범람 | 빠른 록 (160 BPM) | |
| 시즌 2 꽃길 · 안개 숲 | 어두운 동화풍 왈츠 (3/4박자, 144 BPM) | 꽃길: 바람과 풀 / 숲: 부엉이와 물방울 |
| 시즌 2 극장 | 긴박한 현악과 하프시코드 (128 BPM) | 빈 극장의 울림과 삐걱임 |
| 시즌 2 보스 · 시즌 2 보스 토벌 | 광기 어린 서커스풍 관현악 (160 BPM) | |
| 캠프·상점 | 포근한 통기타 (96 BPM) | |

- **환경음은 음악 밑에 깔린다.** 바람 같은 소리는 조금만 커도 음악을 덮으므로, 음악보다 15~20dB 작게 둔다 (실제 섞이는 크기를 재서 맞췄다). 크기는 장소마다 `data/sound/bgm.csv` 의 ambVolume 으로 정한다: 바람이 계속 부는 골목·꽃길은 0.2, 가끔 소리가 나는 숲·극장은 0.3 (음악은 0.8).
- 장소가 바뀌면 1.2초에 걸쳐 넘어간다. 같은 음악을 쓰는 섹터끼리는 끊지 않고 이어 간다 (꽃길 → 안개 숲은 환경음만 바뀐다).
- 보스를 쓰러뜨리면 음악이 먼저 잦아들고, 쓰러지는 동작이 끝난 뒤 토벌 징글이 나온다. 징글(섹터 클리어 / 토벌 / 탈출 / 전멸)이 나는 동안 배경음은 35%로 줄었다가 돌아온다.
- **끊김 없는 반복**: 한 곡은 30초짜리 반복 구간이다 (환경음은 20초). 파일은 "반복 구간 + 맨 앞 1초"로 만들어 두고, 게임은 30초마다 다음 재생을 겹쳐 시작하면서 겹치는 1초 동안 앞의 것을 줄인다. 겹치는 둘은 같은 소리라 크기가 변하지 않고, MP3 가 파일 앞뒤에 넣는 짧은 무음이 이음매에 끼지 않는다. 브라우저에서 두 바퀴를 그려 재 보면 이음매 구간의 크기가 한 주기 전의 0.98~1.04배다.
- 반복 구간이 마디 중간에서 끊기지 않도록, 곡마다 빠르기를 "30초가 마디의 정수배가 되는 값"으로 정했다 (128 BPM = 16마디, 96 BPM = 12마디, 160 BPM = 20마디, 왈츠 144 BPM = 24마디). 만들어진 곡의 빠르기를 재서 지시한 값과 같은지 확인한다.

#### 음량과 브라우저의 제약

- 로비와 팀 정보 창의 "소리" 버튼에서 전체 / 배경음 / 효과음 음량을 정하고 소리를 끌 수 있다. 기본값은 100 / 70 / 90. 설정은 기기에 저장된다.
- 브라우저는 사용자가 화면을 한 번 누르기 전에는 소리를 내지 못한다. 로비 음악은 첫 터치와 함께 시작한다. 효과음 파일(약 1.3MB)은 그 전에 미리 받아 둔다.
- 화면이 꺼지거나 다른 탭으로 가면 소리가 멈추고, 돌아오면 이어진다.
- 아이폰은 옆면의 무음 스위치가 켜져 있으면 웹 페이지의 소리가 나지 않는다.

#### 만드는 방법

`npm run sound` 도구가 표의 지시문으로 소리를 만들고 다듬어 게임 폴더에 놓는다 (README).

1. `data/sound/sounds.csv` 에 소리의 이름, 종류, 길이, 지시문(영어)을 적는다.
2. ElevenLabs 의 효과음 모델(SFX v3)로 만든다. 1초에 10크레딧. 지금까지 138개(410초 분량)에 약 4,700크레딧을 썼다.
3. 다듬기: 앞뒤 무음을 자르고, 끝을 부드럽게 내리고, 크기를 맞춘다 (효과음은 가장 큰 0.2초 구간을 기준으로, 배경음은 전체 평균을 기준으로). 효과음은 한 채널, 배경음과 징글은 두 채널 MP3 로 쓴다. 전체 6.3MB.
4. 소리를 하나씩 들어 보는 페이지가 게임과 함께 올라간다 (`sound/`). 마음에 들지 않는 소리에 표시하면 다시 만들 목록이 모인다.

- **배경 음악의 한계**: ElevenLabs 의 음악 모델은 유료 요금제에서만 API 로 쓸 수 있어, 지금은 효과음 모델의 "끊김 없는 반복" 기능으로 30초 구간을 만들었다 (이 모델이 만들 수 있는 가장 긴 길이다). 유료 요금제로 바꾸면 `sounds.csv` 에서 그 곡의 종류를 `music` 으로 바꿔 더 길고 전개가 있는 곡으로 다시 만들 수 있다. 도구는 음악에서 마디에 맞춰 반복 구간을 잘라 낸다.
- **이용 조건**: 무료 요금제로 만든 소리는 상업적으로 쓸 수 없다. 프로토타입 검증에는 문제가 없지만, 출시할 때는 유료 요금제에서 다시 만들어야 한다.
- 만든 소리가 지시문에 맞는지는 사람이 들어야 알 수 있다. 도구가 확인하는 것은 길이, 크기, 무음, 반복 이음매, 박자의 빠르기까지다.

| 런 1회 시간 | 15~20분 |

### 근접과 원거리의 균형

움직이지 않는 허수아비에 20초 동안 기본 공격과 액티브를 쓴 초당 피해로 비교한다 (궁극기 제외).

| 구분 | 한 마리 | 뭉친 다섯 마리 | 비고 |
| --- | --- | --- | --- |
| 근접 딜러 (에트나, 라온, 하루) | 290~320 | 750~910 | 여러 적을 한꺼번에 친다. 체력이 높다 |
| 원거리 딜러 (라이, 키온, 카렌, 유나) | 350~430 | 420~640 | 한 마리에 강하다. 안전한 거리에서 싸운다 |

- 조정 전에는 근접이 뭉친 무리에 원거리의 2~3배 화력을 냈다 (1,120~1,590 대 420~640). 기본 공격이 범위 안의 모든 적에게 온전한 피해를 줬기 때문이다.
- **다중 타격 감소**: 근접 기본 공격이 여러 적을 한꺼번에 칠 때, 가까운 적부터 차례로 피해가 60%씩 줄어든다 (하한 30%). 다섯 마리를 치면 합계가 5배가 아니라 약 2.6배다. 스킬과 궁극기에는 적용하지 않는다.
- 원거리 기본 공격은 조금 올렸다: 라이 +20%, 유나 +11%, 로아 +11%, 키온 +5%.
- 원거리의 다중 타격은 고유 성장(관통, 튕김, 폭발)으로 늘어난다. 런 후반에는 격차가 더 줄어든다.

자동 플레이(화면 없이 규칙만 돌리는 테스트) 기준으로 런 한 번에 스킬 성장 27~34레벨, 장비 9개, 팀 점수 2,300~3,100이 나온다.
자동 플레이는 공격 예고를 거의 다 피하므로, 사람이 했을 때의 난이도는 폰 테스트로 따로 확인해야 한다.

## 14. 확인이 필요한 사항

아래는 임의로 정한 내용이다. 다르게 가고 싶은 항목만 알려 주면 반영한다.

| 필요해지는 단계 | 항목 | 현재 가정 |
| --- | --- | --- |
| 1단계 | 방향 보정 | D패드 방향 공격에 ±25° 조준 보정을 넣는다 (3.3절) |
| 1단계 | 방향 패드 | 자유 방향 (3.2절). 빠르기는 민 정도와 상관없이 같다. 살짝 밀면 천천히 걷게 할지, 가로·세로 가까이에서 곧게 붙여 줄지는 해 보고 정한다 |
| 1단계 | 추천 타겟 거리 | 캐릭터의 실제 사거리와 같다. 더 멀리 잡으면 닿지 않는 적을 조준하게 된다 |
| 1단계 | 공격 중 D패드 | 공격 버튼을 누르고 있는 동안 D패드는 이동 없이 조준 방향만 바꾼다 |
| 2단계 | 상호작용 버튼의 위치 | 필드 캐릭터 오른쪽에 붙어 따라다닌다. 오른손 엄지가 닿기 어려우면 화면 오른쪽 버튼 묶음 근처에 고정하는 방식으로 바꾼다 |
| 2단계 | 섹터 제한 시간 | 없음. 시간 압박(예: 2분 이후 몬스터 강화)을 넣을지 여부 |
| 2단계 | 체크포인트 위치 | 섹터 3, 6 뒤 두 번 |
| 2단계 | 장비 스킬 보유 범위 | 일반 등급을 포함한 모든 장비가 스킬 1개를 가지고, 희귀도는 스킬 레벨만 올린다 |
| 2단계 | 장비 스킬 발동 주체 | 착용 캐릭터가 필드에 있을 때만 발동한다 ("팀 공통" 악세서리 2종 제외) |
| 2단계 | 무기 스킬의 "공격" 범위 | 적중·치명타·처치 계기는 기본 공격, 액티브, 궁극기 모두에서 발동한다. 횟수를 세는 스킬(초승달 칼날)만 기본 공격 기준이다 |
| 2단계 | 장비 스킬 목록 | 슬롯별 7종은 예시안이다 |
| 2단계 | 목표 난이도 | 미정 (예: 첫 캠프 도달률, 보스 클리어율) |
| 리소스 단계 | 몬스터와 맵의 어울림 | 시즌 1의 몬스터는 아직 도형이다. 시즌 2의 몬스터는 동작 그림까지 들어가 있다 |
| 3단계 | 신규 캐릭터 6명 | 카렌, 라온, 유나, 하루, 로아, 이브는 제안안이다. 이름·무기·스킬 모두 가칭 |
| 3단계 | S급 / A급 차이 | 기본 능력치 약 10% 차이만 있다 |
| 리소스 단계 | 위쪽을 볼 때의 모습 | 뒤쪽 방향 그림을 만들지 않으므로 위로 움직이거나 위를 공격할 때도 앞모습이 나온다. 어색하면 뒤쪽 방향을 추가한다 |
| 리소스 단계 | 스프라이트 속 이펙트 | 공격 동작에 흰 검기만 넣는다. 검기는 그림과 함께 좌우로만 향하므로, 위아래를 공격할 때는 게임이 그리는 공격 범위 표시와 방향이 다르다. 거슬리면 검기를 빼고 다시 만든다 |
| 리소스 단계 | 신규 캐릭터 6명의 외형 | 카렌, 라온, 유나, 하루, 로아, 이브는 추천안으로 만들었다. 바꾸고 싶은 캐릭터는 외형 설명(data/art/subjects.csv)을 고쳐 기본 이미지부터 다시 만든다 |
| 리소스 단계 | 시즌 2 몬스터의 동작 | 7종의 겉모습을 확정하고 동작 그림을 만들었다 (8.6, 8.7절). 마음에 들지 않는 동작은 `data/art/clips.csv` 의 그 몬스터 줄(움직임 설명)을 고쳐 그 동작만 다시 만든다 (한 편 약 0.27달러) |
| 리소스 단계 | 시즌 1 몬스터의 외형 | 없음. 원화나 외형 설명이 정해져야 스프라이트를 만들 수 있다 |
| 소리 | 소리의 느낌 | 지시문으로 만든 그대로 넣었다. 들어 보는 페이지에서 마음에 들지 않는 소리를 표시해 주면 지시문을 고쳐 그 소리만 다시 만든다 (효과음 하나에 5~20크레딧, 배경 음악 한 곡에 300크레딧) |
| 소리 | 음량의 균형 | 효과음이 배경 음악보다 조금 크게, 환경음은 음악보다 훨씬 작게 들리도록 잡았다. 특정 효과음이 크거나 작으면 `data/sound/cues.csv` 의 volume 을, 환경음은 `data/sound/bgm.csv` 의 ambVolume 을 고친다 |
| 소리 | 배경 음악의 길이 | 무료 요금제에서 만들 수 있는 30초 반복 구간이다. 길게 들으면 단조로울 수 있다. 유료 요금제(음악 모델)로 다시 만들지 여부 |
| 소리 | 캐릭터 음성 | 없음. 기합·피격 음성을 넣을지 여부 |
| 출시 전 | 소리의 이용 조건 | 무료 요금제로 만든 소리는 상업적으로 쓸 수 없다. 출시 전에 유료 요금제에서 다시 만든다 |
| 시즌 2 | 긴 맵의 길이 | 100 × 16칸, 무리 8~9. 봇 기준 2분쯤 걸린다. 길거나 짧으면 맵 파일과 sectors.csv 로 조정한다 |
| 시즌 2 | 안개의 역할 | 지금은 분위기(화면 효과)뿐이다. 몬스터가 알아채는 거리를 줄이는 식으로 규칙에 넣을지는 미정 |
| 시즌 2 | 가려진 선택지의 비중 | 55%로 섞여 나온다. 더 자주 또는 덜 나오게 하려면 params.csv 의 route.hiddenChance |
| 선택지 | 30~35번에 무엇을 세는가 | 고르는 창을 모두 센다: 3택 1 보상 + 경로 선택 + NPC 이벤트 + 수상한 보따리. 3택 1 보상만 30~35번으로 잡고 싶으면 `sectors.csv` 의 chests 를 올리고 (시즌 1은 섹터마다 2~3, 시즌 2는 6·6·3·3·4쯤) 몬스터 강화 폭을 되돌린다 |
| 선택지 | 줄어든 성장의 보정 | 몬스터 강화 폭(섹터당 체력 +13%, 공격력 +6%)과 보스 체력(32,000~33,000)을 낮춰 자동 플레이 기준으로 예전과 비슷한 난이도에 맞췄다. 사람이 하기에 쉽거나 어려우면 `params.csv` 의 scaling.* 과 `monsters.csv` 의 보스 체력을 조정한다 |
| 분위기 | 어두운 정도 | 세트마다 `moods.csv` 에 정했다. 너무 어둡거나 밝으면 dark(먼 곳의 밝기)와 sat(채도)을, 전체를 한꺼번에 바꾸려면 `params.csv` 의 mood.strength 를 고친다 |
| 자동 공격 | 궁극기 | 직접 누른다. 자동으로 쓰게 하려면 `params.csv` 의 auto.ult 를 1(차면 바로) 또는 2(강한 적이 있을 때만)로 |
| 자동 공격 | 반경 | 알아챈 적 520px, 알아채지 못한 적 300px. 너무 멀리 쫓아가거나 가만히 서 있는 일이 잦으면 auto.radius / auto.near 를 조정한다 |
| 자동 공격 | 범위 | 싸움만 맡는다. 다음 무리로 걸어가기, 상자 열기, 회피는 직접 한다. 맵을 스스로 도는 자동 사냥으로 넓힐지는 미정 |
| 귀중품 | 은화의 쓰임 | 정해지지 않았다. 지금은 쌓이기만 한다 (런 밖 성장은 프로토타입 범위 밖) |
| 귀중품 | 가방 칸 수 | 4칸 고정. 장비나 성장으로 늘릴지는 미정 |
| 귀중품 | 저주의 지속 | 런이 끝날 때까지. 캠프에서 풀 수 있게 할지는 미정 |
| 귀중품 | 덱 컨텐츠 | 덱 컨텐츠(토벌, 범람)에서는 귀중품이 나오지 않는다 |
| 밸런스 | 근접의 다중 타격 감소 | 가까운 적부터 60%씩 감소(하한 30%). 근접이 여전히 세거나 너무 약해졌으면 params.csv 의 basic.cleaveFalloff 를 조정한다 |
| 밸런스 | 이브의 궁극기 | 직접 피해가 없는 협공형으로 바꿨다. 혼자 쓸 때 밋밋하면 나팔을 불 때의 범위 피해를 일부 되돌린다 |
| 리소스 단계 | 포근이의 애니메이션 | 원화는 받은 그림으로 교체했다. 움직이는 동작(대기, 시전)은 영상 생성 모델이 다시 열리면 만든다 |
