## 0. 확정된 결정 사항

질의 응답으로 확정된 내용이다. 기획 슬라이드와 다른 부분은 이 표가 우선한다.

| 주제 | 결정 |
| --- | --- |
| 속성 | 실체 / 형상 / 자연 / 반전 4종. 슬라이드의 "전이"는 "자연"으로 통일 |
| 속성 작동 | 적 약점 속성(피해 +30%) + 속성별 전투 특성 둘 다 적용 |
| 탄환 | 없음. 기본 공격은 무제한이며 HUD의 탄환 표시는 삭제 |

| 장비 스킬 | 장비마다 스킬 1개. 캐릭터 스킬과 무관하게 자체 작동. 무기 = 공격적 (공격할 때), 방어구 = 방어적 (맞을 때), 악세서리 = 유틸 |

| 프로토타입 용도 | 재미 검증용. 다만 검증 항목이 계속 추가될 수 있으므로 확장하기 쉬운 구조로 만든다 |
| 쿼터뷰 표현 | 비스듬한 탑다운. D패드 위쪽 = 화면 위쪽 |
| HUD | HTML 오버레이. 맵과 전투만 PixiJS |
| 맵 제작 방식 | 맵 디자인(지형)은 고정. 입장할 때마다 오브젝트만 규칙에 따라 무작위 배치 (7.2절) |
| 그래픽 리소스 | 플레이스홀더로 시작. 실제 리소스는 2.5~3등신 SD 캐릭터의 스프라이트 애니메이션 (11.1절) |
| 캐릭터 이름 | 에트나(대검), 라이(메카 건틀렛), 키온(활)으로 확정. 이전 가칭은 서린 / 미도 / 시아. 표와 파일의 내부 이름(serin, mido, sia)은 저장 데이터와 그림 폴더 때문에 그대로 둔다 |
| 스프라이트 방향 | 앞쪽 사선 한 방향만 만들고 좌우 반전해 쓴다. 뒤쪽 방향 그림은 만들지 않는다 (11.1절) |
| 귀중품과 가방 | 던전에서 주운 귀중품을 4칸짜리 가방에 담아, 살아서 나가는 순간 던전 밖 재화(은화)로 바꾼다. 주울 때 위험을 지고 더 좋은 것을 노리는 선택이 있다 (7.12절) |

## 1. 개요

### 1.1 한 줄 정의

3명의 미소녀 조사원과 펫 1마리로 팀을 꾸려 9개 섹터의 괴담 현장을 탐험하며 빌드를 완성하고,
살아서 탈출한 팀만 "파티덱"으로 남겨 상위 컨텐츠에 도전하는 모바일 쿼터뷰 익스트랙션 로그라이크.

### 1.2 핵심 재미

1. **현장 판단**: 더 위험한 경로로 가서 덱을 키울지, 지금 캠프에서 탈출해 덱을 지킬지.
2. **빌드 완성**: 캐릭터 고유 성장 + 시즌 스킬 + 시즌 장비가 한 런 안에서 쌓여 팀이 완성된다.
3. **교체 전투**: 3명을 상황에 맞게 교체하며 속성 약점과 속성 특성을 활용한다.
4. **탐험**: 일자형이 아닌 맵에서 무리, 수색 오브젝트, NPC를 찾아다닌다.

### 1.3 프로토타입 검증 목표

- D패드 + 공격 시 정지 + 추천 타겟 조작이 모바일에서 손에 맞는가.
- 섹터 1개가 1~2분, 런 1회가 15~20분 안에 끝나는가.
- 한 런에서 만든 파티덱이 런마다 체감될 만큼 다르게 나오는가.
- 탈출 여부를 고민하게 만드는 긴장이 생기는가.

### 1.4 범위

| 포함 | 제외 (구조만 유지) |
| --- | --- |
| 팀 편성 (3 캐릭터 + 1 펫) | 캐릭터 레벨 / 스킬 레벨 / 조사 도구 |
| 시즌 컨텐츠 "괴담 조사" 9섹터 런 | 펫 레벨 / 돌파 |
| 파티덱 저장 (팀 점수 포함) | BM, 재화 / 파견, 이벤트 컨텐츠 |
| 덱 컨텐츠 2종 | 서버, 계정, 랭킹 |
| 전투 HUD 13요소 | 스토리, 연출 컷신, 사운드 |

## 2. 전체 플레이 흐름

```
로비
 ├─ 괴담 조사 (시즌 컨텐츠)
 │    팀 편성 (3C + 1P)
 │      → 섹터 1 → 경로 선택 → 섹터 2 → 경로 선택 → 섹터 3
 │      → [체크포인트 캠프 1: 휴식 / 상점 / 탈출]
 │      → 섹터 4 → 섹터 5 → 섹터 6
 │      → [체크포인트 캠프 2: 휴식 / 상점 / 탈출]
 │      → 섹터 7 → 섹터 8 → 섹터 9 괴이(보스) 전투
 │      → 조사 팀 저장 (파티덱 + 팀 점수)
 │
 └─ 파티덱 컨텐츠 (저장된 덱 필요)
      ├─ 특급 괴이 토벌 (보스 타임어택)
      └─ 괴이 범람 (웨이브 서바이벌)
```

- 경로 선택에서 보너스 맵을 고르면 보너스 맵을 거친 뒤 원래의 다음 섹터로 이어진다.
- 파티덱이 저장되는 경우는 두 가지뿐이다: 캠프에서 탈출하거나, 섹터 9 보스를 격파하거나.
- 그 외(전멸, 런 포기)는 파티덱이 남지 않는다.

## 3. 조작과 전투 규칙

### 3.1 화면

- 스마트폰 가로 고정. 세로로 들면 회전 안내를 띄운다.
- 쿼터뷰(위에서 비스듬히 내려다보는 시점). 카메라는 필드 캐릭터를 따라간다.
- PC 테스트용 키보드 조작을 함께 지원한다 (이동 WASD, 공격 J, 회피 K, 액티브 L, 궁극기 I, 펫 O, 교체 1/2/3).

### 3.2 이동

- 8방향 D패드. 누르고 있는 방향으로 이동하고 손을 떼면 멈춘다.

### 3.3 기본 공격

| 상황 | 동작 |
| --- | --- |
| 공격 버튼을 누름 | 이동이 멈추고 공격을 시작한다. 누르고 있는 동안 반복 공격 |
| D패드 입력 중 + 공격 (근거리 캐릭터) | D패드가 가리키는 8방향으로 공격 |
| D패드 입력 중 + 공격 (원거리 캐릭터) | D패드 방향과 상관없이 추천 타겟에게 공격. 사거리 안에 적이 없을 때만 D패드 방향으로 공격 |
| D패드 미입력 + 공격 | 추천 타겟에게 공격 |
| 추천 타겟이 없음 | 마지막으로 바라본 방향으로 공격 |
| 공격 버튼에서 손을 뗌 | 현재 공격의 후딜레이가 끝나면 이동 가능 |

- **추천 타겟**: 사거리 안에서 가장 가까운 적. 벽에 가려진 적은 제외한다.
  추천 타겟에는 조준 마커를 표시해 누가 맞을지 미리 알려 준다. 근거리 캐릭터는 D패드를 누르지 않는 동안, 원거리 캐릭터는 항상 표시한다.
- **방향 보정(제안)**: 8방향 공격은 빗나가기 쉬우므로, 지정 방향 ±25° 안에 적이 있으면 그 적 쪽으로 보정한다.
- **조준 방식**: 캐릭터마다 표(characters.csv의 aim)에 적는다. 근거리(대검, 해머, 쌍검, 깃창)는 D패드 조준, 원거리(메카 건틀렛, 활, 산탄총, 기관단총, 부적)는 자동 조준이다. 액티브와 궁극기에도 같은 규칙을 쓴다.
- 근거리 캐릭터도 자동 조준으로 해 볼 수 있도록, 디버그 메뉴에 "근거리 자동 조준" 옵션을 둔다.
- 기본 공격의 타격 범위(부채꼴)는 화면에 그리지 않는다. 수치 표(fx.basicRange)를 1로 바꾸면 다시 그린다.
- 근접 캐릭터는 공격할 때 조준 방향으로 짧게 전진한다.
- 회피는 공격 동작을 끊고 나갈 수 있다.

### 3.4 회피

- D패드 방향(미입력 시 바라보는 방향)으로 짧게 대시한다. 대시 중 0.25초 무적.
- 잔여 카운트 기본 2회, 카운트당 3초에 1회 충전.

### 3.5 액티브 스킬 / 궁극기

- 방향 규칙은 기본 공격과 같다 (D패드 방향 또는 추천 타겟).
- **액티브**: 쿨타임 기반. 게이지가 차면 사용 가능. 일부 캐릭터는 잔여 카운트(충전 횟수)를 가진다.
- **궁극기**: 궁극기 게이지 100으로 사용. 공격 적중과 처치로 충전된다.
  필드 캐릭터는 100%, 오프 필드 캐릭터는 30% 비율로 충전된다.

### 3.6 펫 스킬

- 쿨타임 기반 버튼 1개. 팀에 편성한 펫의 스킬을 사용한다.

### 3.7 캐릭터 교체

- 화면 좌측의 교체 캐릭터 썸네일을 누르면 그 캐릭터가 같은 자리에 등장한다.
- 교체 쿨타임 1.5초 (팀 공유). 사망한 캐릭터로는 교체할 수 없다.
- 오프 필드 캐릭터도 액티브 쿨타임은 계속 돈다. 체력은 자연 회복되지 않는다.
- 필드 캐릭터가 사망하면 살아 있는 다음 캐릭터로 자동 교체된다.
- 3명이 모두 사망하면 전멸이다.

### 3.8 피해 계산 (초안)

```
피해 = 공격력 × 스킬 배율 × 치명타(기본 5%, 150%) × 약점 보정(1.3) × 버프·디버프 보정
```

장비 스킬의 피해는 별도 규칙을 쓴다 (7.5절).

### 5.1 분류 체계

**등급 (괴담 대응 등급)**: S급 / A급. 프로토타입에서는 기본 능력치 차이만 둔다 (S급이 약 10% 높음).

**속성 (능력 계통)** — 적 약점 판정과 전투 특성 두 가지에 쓰인다.

| 버프 특화 | 깃발 강화 (3): 깃발 공격력 버프 +5%p · 광역 깃발 (2): 깃발 범위 +25%, 지속 +2초 · 인계 (2): 이브에서 교체해 나갈 때 다음 캐릭터에게 6초간 공격력 +12% |
| 서브 딜링 | 연속 찌르기 (2): 기본 공격 3회마다 추가 찌르기 150% · 깃발 포격 (2): 깃발이 2초마다 범위 안의 적에게 60% 피해 |

### 5.5 궁극기의 작용 방식

궁극기가 "주변에 원형으로 터진다" 일색이 되지 않도록, 캐릭터마다 범위의 모양과 방식을 다르게 둔다.
명조의 공명 해방처럼 같은 궁극기라도 변신형·추적형·협공형·설치형으로 쓰임이 갈리는 구성을 참고했다.

| 캐릭터 | 방식 | 모양 | 잘 맞는 상황 |
| --- | --- | --- | --- |
| 에트나 | 즉발 + 잔류 | 전방 직선 (긴 균열이 남는다) | 좁은 골목, 줄지어 오는 적 |
| 라이 | 추적 | 범위 없음. 가까운 적부터 하나씩 낙뢰 | 흩어진 적, 정예 한 마리에 몰아치기 |
| 키온 | 저격 | 초장거리 관통 직선 + 표식 | 멀리 있는 보스, 뒤이은 딜 준비 |
| 카렌 | 연사 | 코앞의 부채꼴 5연사 | 달라붙은 무리. 끝나면 회피와 액티브가 돌아와 연계 |
| 라온 | 도약 강타 | 착지 지점의 큰 원 (유일한 원형 폭발) | 뭉친 무리 한가운데 |
| 유나 | 강화 상태 | 범위 없음. 자신의 연사가 강해진다 | 긴 교전, 보스 |
| 하루 | 연속 이동 베기 | 범위 없음. 적 사이를 오가며 벤다 | 흩어진 소형 적 |
| 로아 | 지연 폭발 | 범위 없음. 주변 모든 적에게 표식 → 일괄 폭발, 팀 회복 | 적이 사방에 깔렸을 때, 팀이 위험할 때 |
| 이브 | 협공 상태 | 범위 없음. 필드 캐릭터의 공격에 창이 따라 나간다 | 나팔을 불고 딜러로 교체해 싸우기 |

- 에트나, 라이, 키온은 이미 만든 궁극기 동작(도약해 내리꽂기, 주먹을 들었다 내리치기, 활을 끝까지 당겨 쏘기)을 그대로 쓴다. 판정의 모양만 바뀌었다.
- 이환(Neverness to Everness)의 스킬 구성은 자료를 직접 확인하지 못해 반영하지 못했다. 참고하고 싶은 캐릭터나 영상이 있으면 그 기술의 방식을 옮긴다.

### 5.4 캐릭터 애니 리소스

프로토타입은 도형 기반 플레이스홀더로 표현하되, 상태 구분은 기획 슬라이드의 목록을 따른다.
나중에 스프라이트 애니메이션으로 교체할 때 이 상태 이름을 그대로 쓴다 (11.1절).

기본 공격 (BasicAttack) · 액티브 스킬 (ActiveSkill) · 궁극기 (Ultimate) · 회피 (Escape)

## 6. 펫

괴담 조사 중 아이템 / 스펠처럼 쓰는 펫 스킬 1개를 가진다. 팀에 1마리만 편성한다.

| 펫 | 스킬 | 쿨타임 |
| --- | --- | --- |
| A 펑이 | 가까운 적에게 달려가 자폭. 범위 피해 300% + 넉백 | 14초 |
| B 포근이 | 6초간 회복 구역 생성. 0.5초마다 필드 캐릭터 최대 체력의 2.5% 회복 | 22초 |
| C 느릿이 | 가까운 범위에 6초간 슬로우 장판 생성 (이동 속도 -50%) | 16초 |
| D 든든이 | 조준 방향에 6초간 방벽 생성. 적 투사체 차단 + 적 진로 방해 | 18초 |

- 펫 피해는 팀 3명의 평균 공격력을 기준으로 한다.

## 7. 시즌 컨텐츠 — 괴담 조사

### 7.1 시즌 구조

- 시즌마다 메인 괴담 테마 1개, 테마에 맞춘 섹터 맵, 시즌 스킬, 시즌 장비, 보스를 가진다.
- 프로토타입 시즌: **시즌 1 "그믐밤의 구도심"** — 달이 없는 밤의 낡은 시가지.
- 한 런은 섹터 9개. 섹터 1개의 목표 플레이 시간은 1~2분.

| 섹터 | 구성 | 클리어 후 |
| --- | --- | --- |
| 1 | 일반 섹터 (소형 위주, 학습 구간) | 경로 선택 |
| 2 | 일반 섹터 | 경로 선택 |
| 3 | 일반 섹터 + 출구에 중형 1체 | **체크포인트 캠프 1** → 경로 선택 |
| 4 | 일반 섹터 | 경로 선택 |
| 5 | 일반 섹터 | 경로 선택 |
| 6 | 일반 섹터 + 출구에 중형 정예 | **체크포인트 캠프 2** → 경로 선택 |
| 7 | 일반 섹터 | 경로 선택 |
| 8 | 일반 섹터 | (선택 없이 보스로) |
| 9 | 괴이 (보스) 전투 | 조사 팀 저장 |

### 7.2 섹터 맵

**구조**

- **맵 디자인은 고정이다.** 섹터마다 지형(벽, 건물, 구역, 통로)을 맵 파일로 만들어 둔다.
- **입장할 때마다 오브젝트가 무작위로 배치된다.** 엄폐 오브젝트(상자, 차량, 자판기, 화단), 몬스터 무리, 수색 오브젝트, NPC의 위치가 달라진다.
- 시작 구역에서 출구 구역까지 굽은 주 경로 (6~8 구역) + 막다른 가지 구역 2~4개로 디자인한다.
- 구역 사이는 좁은 골목 입구일 수도, 벽 없이 트인 광장일 수도 있다.
- 오브젝트와 벽은 이동과 투사체를 모두 막는다. 엄폐물로 쓸 수 있다.
- 맵 크기 기준: 가로 50칸 × 세로 32칸 (1칸 = 캐릭터 2명 폭). 화면에는 약 17 × 9칸이 보인다.

**무작위 배치 규칙**

무작위 배치가 진행을 막지 않도록 아래 규칙을 지킨다.

| 규칙 | 내용 |
| --- | --- |
| 통로 보장 | 맵 파일에 "통로"로 지정한 칸(주 동선, 폭 2칸 이상)에는 엄폐 오브젝트를 놓지 않는다 |
| 배치 가능 칸 | 엄폐 오브젝트는 "바닥" 칸에만 놓인다. 시작·출구·무리·수색·NPC 위치와 그 주변 1칸은 비운다 |
| 간격 | 오브젝트 덩어리 사이는 최소 1칸을 띄워 캐릭터가 지나갈 틈을 남긴다 |
| 밀도 | 맵별 밀도 값(바닥 칸 대비 %)으로 오브젝트 양을 조절한다 |
| 도달 검증 | 배치 후 시작 지점에서 출구와 모든 무리·수색 오브젝트·NPC까지 걸어갈 수 있는지 검사하고, 길을 막는 오브젝트는 제거한다 |
| 후보 위치 | 무리, 수색 오브젝트, NPC는 맵 파일에 표시한 후보 위치 중 일부를 뽑아 쓴다. 출구 수호 무리는 항상 같은 자리다 |
| 최소 거리 | 무리는 시작 지점에서 일정 거리 이상, 서로도 일정 거리 이상 떨어진 후보만 뽑는다 |

**배치 요소**

| 요소 | 규칙 |
| --- | --- |
| 몬스터 무리 | 섹터당 4~6무리. 주 경로와 가지 구역에 배치. 가까이 가거나 공격하면 무리 전체가 반응 |
| 출구 수호 무리 | 출구 구역의 무리. 처치해야 출구가 열린다 |
| 보상 상자 | 무리를 전멸시키면 그 자리에 생긴다. 다가가 상호작용 버튼을 누르면 3택 1 선택 |
| 수색 오브젝트 | 섹터당 4~6개. 다가가 상호작용 버튼을 누르면 수색을 시작하고, 0.8초 동안 근처에 머무르면 보상을 얻는다. 벗어나면 취소된다 |
| NPC | 섹터당 0~1명 (약 60% 확률). 다가가 상호작용 버튼을 누르면 랜덤 이벤트 |
| 출구 | 수호 무리 처치 후 활성화. 다가가 상호작용 버튼을 누르면 섹터 클리어 |

**수색 오브젝트 종류**

| 오브젝트 | 보상 |
| --- | --- |
| 보급 상자 | 괴담 조각 (재화) |
| 구급 상자 | 팀 전원 체력 회복 |
| 괴담의 잔재 | 팀 공격력 +3% / 최대 체력 +4% / 치명타 확률 +2% 중 하나가 무작위로 오른다. 런이 끝날 때까지 유지 |
| 봉인 상자 | 열면 괴이 무리가 소환된다. 처치하면 희귀 이상 보상 상자 |

**퀘스트 (HUD ⑩)**

- 주 목표: 출구를 지키는 괴이 처치 → 출구로 이동
- 보조 목표: 괴이 무리 처치 n / m, 오브젝트 수색 n / m

모든 무리를 잡을 필요는 없다. 가지 구역까지 탐험할수록 보상이 늘고 위험과 시간도 늘어난다.

### 7.3 보상 — 업그레이드 선택

**발생 시점**

| 시점 | 내용 |
| --- | --- |
| 무리 처치 | 보상 상자에 다가가면 즉시 3택 1 |
| 섹터 클리어 | 출구 진입 시 3택 1을 1회 추가 |
| 봉인 상자 무리 처치 | 희귀 이상 보장 3택 1 |

**선택지 종류**

| 선택지 | 내용 | 구분 |
| --- | --- | --- |
| 장비 | 각 캐릭터의 장비 슬롯에 장착. 장비마다 장비 스킬 1개 보유 | 시즌 장비: 무기 / 방어구 / 악세서리·심볼 |
| 스킬 성장 | 캐릭터의 스킬 성장 분기 또는 추가 스킬 | 고유 스킬 / 시즌 업그레이드 스킬 / 펫 스킬 |
| 장비 교체 | 장비를 교체하면 기존 장비는 컨텐츠 재화로 환산 | |
| 성장 구입 | 특정 장비 또는 성장 선택지를 컨텐츠 재화로 구매 | 특정 장비 / 랜덤·특정 캐릭터 스킬 성장 |

- 3택 1은 보통 고유 스킬 1 + 시즌 스킬 1 + 장비 1로 구성한다. 건너뛰면 괴담 조각을 받는다.
- 고유 스킬은 현재 팀에 편성된 캐릭터의 것만 나온다.
- 선택지 품질은 무리 등급과 섹터 위험 등급에 따라 올라간다.

**컨텐츠 재화**: 괴담 조각. 런 안에서만 쓰이고 런이 끝나면 사라진다.

### 7.5 시즌 장비

- 캐릭터마다 슬롯 3개: 무기 / 방어구 / 악세서리·심볼.
- 장비 1개 = **장비 스킬 1개 + 능력치 옵션**.
- 장비 선택지를 고르면 장착할 캐릭터를 지정한다. 이미 장착한 슬롯이면 기존 장비는 괴담 조각으로 환산된다.

#### 장비 스킬 원칙

장비 스킬은 캐릭터의 스킬(기본 공격 / 액티브 / 궁극기 / 패시브 / 고유 성장)과 상관없이 장비 자체로 작동한다.
어떤 캐릭터가 착용해도 같은 효과를 낸다. 슬롯이 스킬의 성격과 발동 계기를 정한다.

| 슬롯 | 성격 | 발동 계기 |
| --- | --- | --- |
| 무기 | 공격적 | 착용 캐릭터가 공격할 때 — 공격 사용 / 적중 / 치명타 / 처치 |
| 방어구 | 방어적 | 착용 캐릭터가 맞을 때 — 피격 / 체력 저하 / 치명적 피해 |
| 악세서리·심볼 | 유틸 | 전투 흐름과 탐험 — 교체 / 회피 / 스킬 사용 / 수색 / 상시 |

- **발동 주체**: 착용 캐릭터가 필드에 있을 때만 발동한다. "팀 공통" 표시가 있는 악세서리 스킬은 착용 캐릭터가 오프 필드여도 적용된다.
- **피해 규칙**: 장비 스킬 피해 = 착용 캐릭터 공격력 × 장비 스킬 배율 × 약점 보정.
  치명타가 발생하지 않고, 캐릭터 고유 성장과 포지션 시즌 스킬의 피해 보정을 받지 않는다.
  장비 스킬의 피해는 다른 장비 스킬을 다시 발동시키지 않는다.
- **발동 제한**: 발동형 스킬은 자체 확률 또는 자체 쿨타임을 가진다.
- **스킬 레벨**: 장비의 희귀도가 장비 스킬 레벨을 정한다. 아래 스킬 표에서 굵게 표시한 수치에 레벨 배율이 곱해진다.

| --- | --- | --- | --- |

### 7.7 경로 선택

섹터를 클리어하면 다음 섹터의 경로를 고른다. 경로가 다음 맵 몬스터의 등급과 보상을 정한다.

| 경로 | 몬스터 | 보상 |
| --- | --- | --- |
| 일반 경로 | 일반 등급 위주 | 기본 |
| 정예 경로 | 무리당 몬스터 수 증가, 절반의 무리에 정예 포함, 출구에 중형 | 희귀 확률 상승, 괴담 조각 +50% |
| 특급 경로 | 모든 무리에 정예 포함, 특급 몬스터 출현, 능력치 +25% | 클리어 보상 영웅 이상 보장, 괴담 조각 +100% |
| 보너스 맵 (가끔 등장) | 몬스터 없음 또는 소수 | 보급 창고: 수색 오브젝트 다수 + 보상 상자 1개. 이후 원래 다음 섹터로 진행 |

- 매번 2~3개가 제시된다. 보너스 맵은 약 35% 확률로 선택지에 추가된다.
- 특급 경로는 섹터 3을 클리어한 뒤부터 나온다.
- 섹터 클리어 보상의 품질은 그 섹터에 들어올 때 고른 경로를 따른다.
- 위험한 경로를 고를수록 팀 점수도 올라간다 (7.10절).

**파티덱에 저장되는 것**

### 7.11 런 중간 저장

폰 브라우저는 탭을 자주 닫아 버리므로 진행 중인 런을 자동 저장한다.

| 상황 | 처리 |
| --- | --- |
| 섹터 클리어 후 보상·경로 선택을 마침 | 자동 저장 |
| 캠프에서 "계속 조사"를 고름 | 자동 저장 |
| 섹터 도중 게임을 닫음 | 로비의 "이어하기"로 그 섹터 처음부터 다시 시작. 오브젝트 배치는 다시 뽑는다 |
| 전멸 / 런 포기 / 탈출 / 보스 격파 | 저장된 런 삭제 |

섹터 도중 닫으면 그 섹터를 다시 할 수 있어 전멸 규칙을 피하는 수단이 될 수 있다. 프로토타입에서는 허용한다.

### 7.12 귀중품과 가방

런 안의 성장(스킬, 장비)과 별개로, **던전 밖으로 들고 나가야 값어치가 생기는 물건**을 줍는다. 익스트랙션의 긴장감을 만드는 장치다.

| 항목 | 내용 |
| --- | --- |
| 귀중품 | 13종, 등급 4단계 (평범 / 희귀 / 진귀 / 전설). 등급이 높을수록 은화 가치가 크다 (24 ~ 580) |
| 가방 | 4칸. 가득 찬 상태에서 새것을 얻으면 가방의 물건과 새 물건 가운데 하나를 골라 버린다 |
| 교환 | 캠프에서 탈출하거나 보스를 쓰러뜨려 런을 끝내는 순간, 가방의 귀중품이 전부 은화로 바뀐다 |
| 잃는 경우 | 전멸하거나 조사를 포기하면 가방째 잃는다 |
| 은화 | 던전 밖 재화. 기기에 쌓이고 로비에 표시된다. 쓰는 곳은 아직 없다 |

**얻는 곳**

| 곳 | 내용 |
| --- | --- |
| 수상한 보따리 | 수색 오브젝트의 한 종류로 맵 구석에 놓인다. 열면 아래의 선택 창이 뜬다 |
| 보상 상자 | 스킬·장비를 고른 뒤, 확률로 귀중품이 함께 나온다 (일반 무리 20%, 정예 50%, 특급 100%) |
| 보스 | 쓰러뜨리면 진귀 등급 이상이 반드시 하나 나온다 |

귀중품의 등급은 섹터가 깊을수록 높게 나온다 (섹터 1~3 / 4~6 / 7~9 세 구간).

**수상한 보따리의 선택** (열 때마다 세 종류 가운데 하나가 나온다)

| 종류 | 선택지 |
| --- | --- |
| 평범한 보따리 | 보이는 것만 챙긴다 (안전) / 바닥까지 뒤진다 (한 등급 높은 것, 50% 확률로 저주) |
| 오염된 물건 | 오염된 채로 챙긴다 (가치 1.8배, 들고 있는 동안 저주) / 정화해서 챙긴다 (팀 체력 15% 소모) / 두고 간다 |
| 괴이의 거래 | 대가를 치른다 (두 등급 높은 것, 확정 저주) / 거절하고 굴러 나온 것만 줍는다 (한 등급 낮은 것) |

**저주** — 귀중품을 무리해서 챙긴 대가

| 저주 | 효과 |
| --- | --- |
| 부서진 몸 | 받는 피해 +12% |
| 빠진 기력 | 공격력 -8% |
| 무거운 발 | 이동 속도 -8% |
| 옅어진 숨 | 최대 체력 -10% |
| 흐린 눈 | 치명타 확률 -6%p |

- 선택으로 받은 저주는 런이 끝날 때까지 남는다 (최대 5개). 팀 전원에게 적용된다.
- 오염된 물건의 저주는 그 물건을 들고 있는 동안만 걸린다. 팀 정보 화면에서 버리면 풀린다.
- HUD 오른쪽 위에 가방 칸 수가 표시되고, 팀 정보 화면에서 가방 내용과 나갔을 때의 은화 합계를 볼 수 있다.
- 섹터 사이 자동 저장에 가방과 저주가 함께 저장된다.

### 8.5 괴이 (보스) — "그믐의 우산"

- 대형. 약점 속성 1개 (런마다 무작위, 편성 화면에서 미리 공개).
- 페이즈 3단계. 체력 66%, 33%에서 전환하며 전환 순간 잠시 무적 + 충격파.

| 페이즈 | 패턴 |
| --- | --- |
| 1 | 방사형 탄막, 조준 부채꼴 탄, 플레이어 위치 연속 내려찍기 |
| 2 | 1페이즈 패턴 + 직선 돌진 + 소형 몬스터 소환 |
| 3 | 회전 나선 탄막 추가, 전체 패턴 속도 상승 |

## 9. 파티덱 컨텐츠

저장된 파티덱을 골라 입장한다. 덱의 빌드는 고정이며 컨텐츠 안에서는 성장하지 않는다.

### 9.1 특급 괴이 토벌 (보스 타임어택)

| 항목 | 내용 |
| --- | --- |
| 형식 | 원형 전투장에서 강화 보스 1체와 전투 |
| 난이도 | 1~5단계. 단계마다 보스 체력 +60%, 공격력 +20%. 권장 팀 점수는 1,500부터 단계마다 +500 |
| 제한 시간 | 3분 |
| 결과 | 클리어 타임에 따라 등급 (70초 이내 S / 110초 이내 A / 그 외 B). 덱별·난이도별 최고 기록 저장 |
| 실패 | 전멸 또는 시간 초과. 실패해도 조사 팀은 사라지지 않는다 |

### 9.2 괴이 범람 (웨이브 서바이벌)

| 항목 | 내용 |
| --- | --- |
| 형식 | 닫힌 전투장에서 계속 몰려오는 웨이브를 버틴다 |
| 진행 | 30초마다 웨이브 단계 상승 (총 6단계). 단계마다 몬스터 체력 +22%, 공격력 +8%, 무리가 나타나는 간격이 짧아지고 중형·정예가 섞인다 |
| 제한 시간 | 3분 (끝까지 버티면 완주) |
| 결과 | 점수 = 처치 점수 + 생존 시간 보너스 (초당 2점) + 완주 보너스 500점. 덱별 최고 점수 저장 |
| 실패 | 전멸 시 그 시점까지의 점수로 종료하고 기록한다 |

두 컨텐츠는 덱의 성격을 다르게 시험한다. 보스전은 단일 대상 화력과 생존, 범람은 광역 처리와 지속력.

### 11.1 그래픽 리소스 제작 방식

| 항목 | 내용 |
| --- | --- |
| 캐릭터 형태 | 2.5~3등신 SD 캐릭터. 전투는 SD 캐릭터로 진행한다 (전신 디자인은 원화 기준 자료) |
| 표현 | 스프라이트 애니메이션 |
| 이미지 제작 | 게임에 들어가는 이미지 리소스는 전부 Codex 이미지 생성 도구로 만든다 (캐릭터, 몬스터, 맵 타일, 오브젝트, 아이콘) |
| 애니메이션 제작 | Seedance 2.5 API로 동작 영상을 만들고, 영상에서 프레임을 뽑아 스프라이트 시트로 변환해 게임에 적용한다 |
| 프로토타입 단계 | 플레이스홀더. 캐릭터는 머리색·의상색·무기로 구분되는 도형 SD. 스프라이트 시트가 등록된 캐릭터는 스프라이트로 그린다 |

플레이스홀더에서 실제 리소스로 넘어갈 때 다시 만들지 않도록 다음을 지킨다.

- 캐릭터·몬스터의 표시부는 교체할 수 있는 부품으로 분리한다. 전투 규칙 코드는 "어떤 상태(대기 / 이동 / 기본 공격 …)인지, 어느 방향을 보는지"만 알려 주고, 그것을 도형으로 그릴지 스프라이트로 그릴지는 표시부가 정한다.
- 상태 이름은 5.4절(캐릭터)과 8.4절(몬스터)의 목록을 그대로 쓴다. 스프라이트 시트도 이 이름으로 묶는다.
- 타격 타이밍(선딜레이, 판정 시점, 후딜레이)은 수치 테이블에 두어, 나중에 애니메이션 길이에 맞춰 조정할 수 있게 한다.

#### 제작 과정

원화 한 장에서 게임용 스프라이트까지 네 단계다. 실행 방법은 README의 "스프라이트 제작" 참고.

| 단계 | 내용 | 규칙 |
| --- | --- | --- |
| 1. 기본 이미지 | Codex로 원화를 2.5등신 SD의 대기 자세로 그린다. 방향마다 1장 | 정사각형, 단색 배경(캐릭터에 없는 색: 초록 / 자홍 / 파랑), 캐릭터 키는 화면 높이의 45~55%. 여백은 무기를 휘두를 공간이다 |
| 2. 동작 영상 | 기본 이미지를 첫 프레임으로 Seedance가 동작 영상을 만든다 | 카메라 고정, 배경 단색 유지. 공격 동작은 무기를 따라가는 흰 검기만 허용하고, 그 밖의 이펙트는 넣지 않는다(게임이 따로 그린다). 반복 동작과 제자리로 돌아오는 동작은 끝 프레임도 기본 이미지로 지정한다. 단발 동작은 기본 이미지를 70% 크기로 줄여 넣어, 휘두른 무기가 화면 밖으로 잘리지 않게 여백을 둔다 |
| 3. 프레임 | 배경색을 빼고, 쓸 구간에서 프레임을 고른다 | 반복 동작은 한 주기를 같은 간격으로 고른다. 단발 동작은 실제로 움직이는 구간에서, 움직임이 빠른 곳일수록 촘촘하게 고른다. 자동으로 잡은 구간이 어색하면 초 단위로 직접 지정한다 |
| 4. 시트 | 한 캐릭터의 모든 동작을 시트 이미지에 모은다 | 시트 한 장은 2048px 이하. 프레임은 여백을 잘라 넣는다 |

- **크기와 위치의 기준**: 모든 동작 영상이 같은 기본 이미지에서 시작하므로, 기본 이미지에서 잰 발 위치와 키를 모든 프레임에 똑같이 적용한다. 그래서 동작이 바뀌어도 캐릭터가 튀거나 크기가 달라지지 않는다.
- **방향**: 화면 기준 앞쪽 사선(SE) 한 방향만 만들고, 좌우 반전으로 왼쪽·오른쪽을 표현한다. 위쪽으로 움직일 때도 앞모습이 나온다. 반전하면 무기 든 손과 머리 장식의 좌우가 바뀐다. 표의 방향 칸에 방향을 더 적으면 그 방향 그림도 만들 수 있다 (비용이 방향 수만큼 늘어난다).
- **없는 동작**: 그림이 아직 없는 동작은 가까운 동작으로 대신한다 (이동 → 대기, 액티브 → 기본 공격, 궁극기 → 액티브, 회피 → 이동 등). 그래서 대기 동작 하나만 있어도 게임에 넣을 수 있고, 동작을 하나씩 늘려 가면 된다.
- **타이밍**: 단발 동작은 규칙이 정한 동작 길이에 맞춰 재생한다. 프레임마다 원래 영상에서의 시점을 기억해 두어, 준비 자세는 천천히, 휘두르는 순간은 빠르게 넘어가는 원래의 빠르기 변화가 그대로 나온다. 공격 동작은 가장 빠르게 움직이는 순간을 "타격 지점"으로 자동으로 잡아, 그 프레임이 규칙상의 타격 시점에 오도록 맞춘다 (표에 숫자를 적으면 그 값을 쓴다).
- **기본 공격 연속기**: `BasicAttack1`, `BasicAttack2` … 처럼 단계별 동작을 만들면 연속기 순서대로 쓴다. 하나(`BasicAttack`)만 있으면 모든 단계에 그것을 쓴다. 에트나은 3연격에 맞춰 가로 베기 → 올려 베기 → 내려찍기 세 동작을 쓴다.
- **프레임 수**: 대기 8장, 이동 8장, 공격 12~16장. 영상은 초당 24장으로 만들어지고 그중 일부를 골라 쓰므로, 프레임 수는 표에서 바꾼 뒤 3·4단계만 다시 돌리면 된다 (영상을 다시 만들지 않으므로 비용이 들지 않는다).
- **표**: 만들 대상과 동작 목록, 영상·배경 제거 설정은 `data/art/` 의 표에서 고친다 (subjects.csv, clips.csv, settings.csv).

| 항목 | 기준 |

| 중형 몬스터 체력 | 1,100~1,500 |

| 섹터당 선택 횟수 | 3~6회 (무리 처치 + 클리어 보상) |

| 장비 스킬 비중 | 완성된 덱 기준 팀 총 피해의 15~25%. 캐릭터 스킬을 대체하지 않고 보조하는 수준 |
| 런 1회 시간 | 15~20분 |

### 근접과 원거리의 균형

움직이지 않는 허수아비에 20초 동안 기본 공격과 액티브를 쓴 초당 피해로 비교한다 (궁극기 제외).

| 구분 | 한 마리 | 뭉친 다섯 마리 | 비고 |
| --- | --- | --- | --- |
| 근접 딜러 (에트나, 라온, 하루) | 290~320 | 750~910 | 여러 적을 한꺼번에 친다. 체력이 높다 |
| 원거리 딜러 (라이, 키온, 카렌, 유나) | 350~430 | 420~640 | 한 마리에 강하다. 안전한 거리에서 싸운다 |

- 조정 전에는 근접이 뭉친 무리에 원거리의 2~3배 화력을 냈다 (1,120~1,590 대 420~640). 기본 공격이 범위 안의 모든 적에게 온전한 피해를 줬기 때문이다.
- **다중 타격 감소**: 근접 기본 공격이 여러 적을 한꺼번에 칠 때, 가까운 적부터 차례로 피해가 60%씩 줄어든다 (하한 30%). 다섯 마리를 치면 합계가 5배가 아니라 약 2.6배다. 스킬과 궁극기에는 적용하지 않는다.
- 원거리 기본 공격은 조금 올렸다: 라이 +20%, 유나 +11%, 로아 +11%, 키온 +5%.
- 원거리의 다중 타격은 고유 성장(관통, 튕김, 폭발)으로 늘어난다. 런 후반에는 격차가 더 줄어든다.

## 13. 구현 단계

| 단계 | 내용 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| 1. 전투 코어 | 맵 1개, 이동, 공격 규칙, 추천 타겟, 회피, 교체, HUD. 캐릭터 3명 (에트나 / 라이 / 키온), 소형 몬스터 4종 | 폰에서 한 섹터를 조작해 클리어할 수 있다 | 구현 완료. 폰 실기 확인 필요 |
| 2. 시즌 런 루프 | 섹터 무작위 배치, 보상 3택 1, 장비와 장비 스킬, 수색 오브젝트, NPC 이벤트, 경로 선택, 캠프, 보스, 파티덱 저장 | 편성부터 덱 저장까지 한 런이 끊기지 않는다 | 구현 완료. 중형 몬스터 2종, 정예·특급 등급, 펫 4종, 이어하기, 디버그 메뉴 포함 |
| 3. 로스터 확장 | 캐릭터 9명, 고유 성장 전체 | 어떤 3명 조합으로도 런이 성립한다 | 구현 완료. 무작위 3명 조합 40회 자동 플레이로 확인 |
| 4. 덱 컨텐츠 | 특급 괴이 토벌, 괴이 범람, 기록 저장 | 저장한 덱으로 두 컨텐츠를 플레이하고 기록이 남는다 | 구현 완료 |
| 5. 다듬기 | 밸런스, 이펙트, 모바일 성능 | 런 1회 15~20분, 저사양 폰에서 끊김 없음 | 예정. 폰 실기 테스트 결과를 받아 진행 |
| 리소스 준비 | 스프라이트 제작 도구(기본 이미지 → 영상 → 프레임 → 시트), 스프라이트 표시부, 맵 그림 제작 도구 | 원화 한 장에서 게임 속 스프라이트까지 명령으로 이어진다 | 구현 완료. 맵은 전부 그림으로 교체. 캐릭터는 에트나·라이·키온 적용, 나머지 6명과 일부 동작은 영상 생성 한도가 풀리면 진행. 몬스터는 외형이 정해지면 진행 |

자동 플레이(화면 없이 규칙만 돌리는 테스트) 기준으로 런 한 번에 스킬 성장 27~34레벨, 장비 9개, 팀 점수 2,300~3,100이 나온다.
자동 플레이는 공격 예고를 거의 다 피하므로, 사람이 했을 때의 난이도는 폰 테스트로 따로 확인해야 한다.

## 14. 확인이 필요한 사항

아래는 임의로 정한 내용이다. 다르게 가고 싶은 항목만 알려 주면 반영한다.

| 필요해지는 단계 | 항목 | 현재 가정 |
| --- | --- | --- |
| 1단계 | 방향 보정 | 8방향 공격에 ±25° 조준 보정을 넣는다 (3.3절) |
| 1단계 | 추천 타겟 거리 | 캐릭터의 실제 사거리와 같다. 더 멀리 잡으면 닿지 않는 적을 조준하게 된다 |
| 1단계 | 공격 중 D패드 | 공격 버튼을 누르고 있는 동안 D패드는 이동 없이 조준 방향만 바꾼다 |
| 2단계 | 상호작용 버튼의 위치 | 필드 캐릭터 오른쪽에 붙어 따라다닌다. 오른손 엄지가 닿기 어려우면 화면 오른쪽 버튼 묶음 근처에 고정하는 방식으로 바꾼다 |
| 2단계 | 섹터 제한 시간 | 없음. 시간 압박(예: 2분 이후 몬스터 강화)을 넣을지 여부 |
| 2단계 | 체크포인트 위치 | 섹터 3, 6 뒤 두 번 |
| 2단계 | 장비 스킬 보유 범위 | 일반 등급을 포함한 모든 장비가 스킬 1개를 가지고, 희귀도는 스킬 레벨만 올린다 |
| 2단계 | 장비 스킬 발동 주체 | 착용 캐릭터가 필드에 있을 때만 발동한다 ("팀 공통" 악세서리 2종 제외) |
| 2단계 | 무기 스킬의 "공격" 범위 | 적중·치명타·처치 계기는 기본 공격, 액티브, 궁극기 모두에서 발동한다. 횟수를 세는 스킬(초승달 칼날)만 기본 공격 기준이다 |
| 2단계 | 장비 스킬 목록 | 슬롯별 7종은 예시안이다 |
| 2단계 | 목표 난이도 | 미정 (예: 첫 캠프 도달률, 보스 클리어율) |
| 리소스 단계 | 몬스터와 맵의 어울림 | 맵은 그림으로 바뀌었지만 몬스터는 아직 도형이다. 몬스터 외형이 정해지면 같은 방식으로 만든다 |
| 3단계 | 신규 캐릭터 6명 | 카렌, 라온, 유나, 하루, 로아, 이브는 제안안이다. 이름·무기·스킬 모두 가칭 |
| 3단계 | S급 / A급 차이 | 기본 능력치 약 10% 차이만 있다 |
| 리소스 단계 | 위쪽을 볼 때의 모습 | 뒤쪽 방향 그림을 만들지 않으므로 위로 움직이거나 위를 공격할 때도 앞모습이 나온다. 어색하면 뒤쪽 방향을 추가한다 |
| 리소스 단계 | 스프라이트 속 이펙트 | 공격 동작에 흰 검기만 넣는다. 검기는 그림과 함께 좌우로만 향하므로, 위아래를 공격할 때는 게임이 그리는 공격 범위 표시와 방향이 다르다. 거슬리면 검기를 빼고 다시 만든다 |
| 리소스 단계 | 신규 캐릭터 6명의 외형 | 카렌, 라온, 유나, 하루, 로아, 이브는 추천안으로 만들었다. 바꾸고 싶은 캐릭터는 외형 설명(data/art/subjects.csv)을 고쳐 기본 이미지부터 다시 만든다 |
| 리소스 단계 | 몬스터의 외형 | 없음. 원화나 외형 설명이 정해져야 스프라이트를 만들 수 있다 |
| 귀중품 | 은화의 쓰임 | 정해지지 않았다. 지금은 쌓이기만 한다 (런 밖 성장은 프로토타입 범위 밖) |
| 귀중품 | 가방 칸 수 | 4칸 고정. 장비나 성장으로 늘릴지는 미정 |
| 귀중품 | 저주의 지속 | 런이 끝날 때까지. 캠프에서 풀 수 있게 할지는 미정 |
| 귀중품 | 덱 컨텐츠 | 덱 컨텐츠(토벌, 범람)에서는 귀중품이 나오지 않는다 |
| 밸런스 | 근접의 다중 타격 감소 | 가까운 적부터 60%씩 감소(하한 30%). 근접이 여전히 세거나 너무 약해졌으면 params.csv 의 basic.cleaveFalloff 를 조정한다 |
| 밸런스 | 이브의 궁극기 | 직접 피해가 없는 협공형으로 바꿨다. 혼자 쓸 때 밋밋하면 나팔을 불 때의 범위 피해를 일부 되돌린다 |
| 리소스 단계 | 포근이의 애니메이션 | 원화는 받은 그림으로 교체했다. 움직이는 동작(대기, 시전)은 영상 생성 모델이 다시 열리면 만든다 |
